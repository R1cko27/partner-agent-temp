# Настройка устройства

Настройка устройства (Описание)
Настройка CLI   Настройка интерфейса командной строки производится на уровне settings cli. Чтобы задать уровень детализации диагностики используется следующая команда:   Admin@UGOS# set settings cli...
Настройка кластеров
Настройка кластера конфигурации    Данный раздел находится на уровне settings device-mgmt configuration-cluster.   Команда обновления существующего узла кластера: Admin@UGOS# set settings device-mgmt...
Настройка управления доступом к консоли NGFW
Настройка данного раздела производится на уровне settings administrators. В данном разделе описаны настройка параметров защиты учётных записей, настройка администраторов и их профилей.   Общие...
Настройка сертификатов
Раздел Сертификаты находится на уровне settings certificates.   Для импорта сертификатов предназначена команда:   Admin@UGOS# import settings certificates   Далее необходимо указать параметры:      ...
Настройка параметров устройства
Изменение параметров устройства производится на уровне settings device. Для изменения используется следующая команда (где <setting-name> — название параметра):   Admin@UGOS# set settings...
Настройка телеметрии
Набор команд для просмотра и настройки режима работы телеметрии доступны на уровне settings telemetry. Телеметрия позволяет отправлять разработчику анонимную статистику, такую как популярность...
Настройка прокси-сервера
Набор команд для просмотра и настройки параметров прокси-сервера доступны на уровне settings proxy. Позволяет настроить такие параметры, как добавление заголовков HTTP — via и forwarded, а также...

Изменение параметров устройства производится на уровне settings device. Для изменения используется следующая команда (где <setting-name> - название параметра):   Admin@UGOS# set settings...
