# Приложения

Documentation:
Элемент библиотеки
Приложения
позволяет создать группы приложений для более удобного использования в правилах фильтрации сетевого трафика. Например, администратор может создать группу приложений «Бизнес приложения» и поместить в нее необходимые приложения.
Для добавления новой группы приложений необходимо выполнить следующие шаги:
Наименование
Описание
Шаг 1.
Создать группу приложений.
В панели
Группы приложений
нажать на кнопку
Добавить
, дать название группе.
Шаг 2.
Добавить приложения.
Выделить созданную группу и в панели
Приложения
, нажать на кнопку
Добавить
и выбрать необходимые приложения из списка.
