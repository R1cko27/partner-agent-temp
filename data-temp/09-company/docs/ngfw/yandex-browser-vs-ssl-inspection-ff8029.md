# Yandex Browser vs SSL inspection

KnowledgeBase:
Задача
Yandex Browser не использует импортированный сертификат UserGate (проблема характерна, в основном, для Linux систем).
Решение
Для доверия сертификату UserGate со стороны Yandex Browser необходимо сделать следующее:
В Яндекс-браузере зайдите в
Настройки ➜ Системные ➜ Управление сертификатами
Импортируйте сертификат UserGate: нажмите
Импорт
и выберите скачанный сертификат UserGate.
Отметьте чекбоксы
Доверять этому сертификату…
Примечание
Если сертификат уже импортирован, то настройка доверия сертификату производится во вкладке
Центры сертификации:
найдите в списке сертификат UserGate и нажмите
Изменить
v6.x
v7.x
Ошибка при настройке интерфейса
Записи о блокировке широковещательных UDP-пакетов заполняют...
