# Изменение настроек при использовании нескольких провайдеров

KnowledgeBase:
Для подключения UserGate к сети Интернет возможно использование нескольких провайдеров. В такой ситуации необходимо указать несколько шлюзов (подробнее смотрите в
UserGate 6. Руководство администратора
При использовании нескольких провайдеров с помощью приоритетов можно настроить резервирование интернет-каналов или режим балансировки. Сделать это можно при указании шлюзов в разделе
Сеть ➜ Шлюзы
, включив чекбокс
Балансировка
или чекбокс
По умолчанию
Если при настройке шлюзов в свойствах нескольких из них включить чекбокс
По умолчанию
, то шлюзом по умолчанию будет назначен последний выбранный шлюз.
При включении режима балансировки необходимо указать вес шлюза: больший вес шлюза соответствует большей доле трафика, которая идет через шлюз. При распределении трафика между шлюзами с разными весами происходит:
Вычисление хэша от адресов источника и назначения.
Выбор шлюза.
Трафик распределяется с учётом весов. Пусть настроены 2 шлюза:
– сессии, проходящие через шлюзы.
– веса шлюзов.
Тогда сессии между шлюзами будут распределяться согласно
n1/w1 = n2/w2
При использовании режима балансировки включение чекбокса
По умолчанию
не оказывает влияния на работу шлюзов, т.е. если одновременно включить чекбоксы
Балансировка
По умолчанию
, то шлюзы будут работать в режиме балансировки в соответствии с указанными весами.
