# Слабый криптографический ключ

Вопрос
Уязвимость:
Слабый криптографический ключ
ID: 8309
Краткое описание:
Обнаружен слабый криптографический ключ. Длина ключа, используемая криптографическим алгоритмом,
определяет уровень безопасности, который может быть достигнут.
Алгоритм (длина ключа): rsaEncryption(1024)
Ответ
В продукте UserGate используются сертификаты по умолчанию (default) с длиной ключа 1024. Для устранения данной уязвимости необходимо заменить сертификат по умолчанию (default) на пользовательский сертификат с требуемой длиной ключа.
443(TCP) - HTTP SSL
623(UDP) - IPMI
