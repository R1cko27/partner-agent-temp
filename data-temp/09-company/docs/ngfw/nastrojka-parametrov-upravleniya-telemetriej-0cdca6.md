# Настройка параметров управления телеметрией

Настройка параметров управления телеметрией устройства в интерфейсе командной строки производится на уровне
settings telementry
Для редактирования параметров используется следующая команда:
Admin@nodename# set settings telemetry <parameters>
Возможна настройка следующих параметров:
Параметр
Описание
enabled
Включение/отключение сбора телеметрии на устройстве:
off
По умолчанию сбор телеметрии включен.
hide-sensitive-data
Включение/отключение функции сокрытия персональных данных в телеметрии (доступно в версии ПО 7.4.0 и выше):
off
По умолчанию функция отключена.
Посмотреть текущие настройки можно с помощью команды:
Admin@nodename# show settings telemetry
v7.x
Настройка профилей клиентских сертификатов
Экспорт и импорт конфигурации в текстовом формате
