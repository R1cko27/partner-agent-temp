# Веб-портал

Documentation:
Раздел
Веб-портал
отображает всех пользователей и все серверы, подключенные через веб-портал к данному серверу. Для каждого соединения отображается следующая информация:
Имя
— имя пользователя, под которым произошла аутентификация соединения.
Начало сессии
— время, когда пользователь подключился к сервису.
Продолжительность
— продолжительность соединения.
IP источника
— IP-адрес пользователя.
Useragent
— useragent пользовательского браузера.
Можно задать период обновления данного окна от 3-х секунд до одной минуты или установить обновление вручную.
Администратор имеет возможность принудительно закрыть определённую сессию. Для этого надо выделить её и нажать кнопку
Закрыть
сессию.
