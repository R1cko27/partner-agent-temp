# Установка ПО UserGate на аппаратных платформах C100, D200, D500, E1000, E3000, F8000

Содержание:
Важно!
Процедура, описанная в этой статье, применима только к аппаратным платформам UserGate C100, D200, D500, E1000, E3000, F8000.
Процедура установки ПО UserGate на аппаратных платформах C100, D200, D500, E1000, E3000, F8000 состоит из следующих этапов:
1. Создание
загрузочного USB-носителя
с образом ПО UserGate.
2. Загрузка образа ПО на аппаратную платформу. Загрузку можно выполнить
одним
из двух способов:
а) с помощью
консольного подключения
б) с помощью
подключения через IPMI
Распаковка образа ПО
на аппаратной платформе.
Примечание
Если вы выполняете обновление версии ПО на устройстве с помощью метода чистой установки, перед началом обязательно сохраните (экспортируйте) параметры настройки устройства, а после завершения установки восстановите (импортируйте) ранее сохраненные параметры.
Важно!
Лицензионные ключи для версий 6 и 7 не взаимозаменяемы. Для обновления до версии 7 требуется получить новый ключ.
Создание загрузочного USB-носителя с образом ПО UserGate

1. Загрузите файл образа прошивки ПО
из личного кабинета UserGate
(требуется авторизация в личном кабинете), либо запросите его в службе технической поддержки UserGate.
2. Загрузите образ установочного носителя
по ссылке

3. Скачайте
ПО Rufus

4. Настройте Rufus, указав следующие параметры:
Устройство

Метод загрузки

4. Когда установочный носитель будет создан, скопируйте образ прошивки ПО, полученный в личном кабинете UserGate, либо предоставленный службой технической поддержки, и сохраните его в директории

Загрузка образа ПО на аппаратную платформу
Загрузку образа ПО на аппаратную платформу можно выполнить
одним
из двух способов:
а) с помощью
консольного подключения
б) с помощью
подключения через IPMI
Загрузка образа ПО с помощью консольного подключения
Если вы выбрали способ загрузки образа ПО на аппаратную платформу с помощью консольного подключения, выполните следующие шаги:
1. Подключите к устройству (ПАК UserGate) внешний монитор и USB-клавиатуру.
2. Войдите в BIOS устройства. Для этого включите устройство и нажмите клавишу Delete после появления на экране следующего оповещения.
3. На вкладке
Boot
перейдите в раздел
USB Device BBS Priorities
; если такой раздел отсутствует, перейдите в раздел
Hard Drive BBS Priorities
4. В параметре
Boot Option #1
выберите USB-носитель с
Ghost4Linux
. Общее количество Boot-опций может отличаться на разных устройствах.
5. Вернитесь в предыдущее меню и установите приоритет загрузки устройств. В параметре
Boot Option #1
выберите USB-накопитель с
Ghost4Linux
(не UEFI раздел).
6 Перейдите на вкладку
Save & Exit
и выберите команду
Save Changes and Reset
После перезагрузки устройство начнет загружаться с USB-накопителя.

Важно!
Для проведения процедуры распаковки образа нельзя использовать компьютер, подключенный через консольный порт к ПАК UserGate, поскольку в консольных программах (putty, securecrt и т. п.) не отображается меню настроек, описанное в этом разделе. Процедура корректно работает только при подключении к ПАК с помощью монитора и USB-клавиатуры (подробнее в главе

Для распаковки образа ПО выполните следующие шаги:
1. В Boot Menu выберите
UserGate image UTM install
и дождитесь окончания загрузки.
2. Выберите пункт меню
Set UTM image
и в следующем окне при помощи клавиши Space выберите образ ПО:
utm-6.<НОМЕР-ВЕРСИИ>-public.hdd.bz2
— для версий 6.x;
ngfw-x86-64-<НОМЕР-ВЕРСИИ>-release-public.hdd.bz2
— для версий 7.x.
3. Выберите пункт меню
Restore
4. Выберите физический диск (например, sda), на котором будет развернут образ ПО.
5 После подтверждения действий начнется распаковка образа.
6. После окончания установки перезагрузите устройство, выбрав пункт меню
Reboot
Poweroff
7. При загрузке устройства войдите в BIOS и на вкладке
Boot
установите загрузку с жесткого диска.
