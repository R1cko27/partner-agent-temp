# Создание сертификатов с помощью программы XCA

Содержание:
KnowledgeBase:
Для создания сертификатов используется бесплатная программа управления сертификатами XCA. Скачать данную программу можно на сайте
https://www.hohnstaedt.de/xca/
Запустите XCA. Создайте базу данных для хранения сертификатов
Файл ➜ Новая база данных
New DataBase
