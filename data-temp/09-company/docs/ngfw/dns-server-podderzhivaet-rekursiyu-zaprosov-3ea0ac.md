# DNS-сервер поддерживает рекурсию запросов.

Вопрос
Уязвимость:
Рекурсия
ID: 1058
CVE: CVE-1999-0024
Дата публикации: 13.08.1997
Описание:
DNS-сервер поддерживает рекурсию запросов. При определенных обстоятельствах злоумышленник может
вызвать на сервере отказ в обслуживании.
Ответ
В продукте UserGate ограничена глубина рекурсии DNS запросов, в связи с этим вызвать отказ в обслуживании данным способом не представляется возможным, данная уязвимость не применима к продукту UserGate.
53(UDP)-DNS Отказ в обслуживании.
443(TCP) - HTTP SSL
