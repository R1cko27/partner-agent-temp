# Лицензирование UserGate NGFW

Содержание:
Documentation:
Для использования UserGate NGFW необходима
базовая лицензия
, в рамках которой предоставляется доступ к основным функциям устройства. Чтобы получать обновления UserGate NGFW и использовать его расширенные функции, вам необходимо приобрести
дополнительные лицензии
В веб-интерфейсе UserGate NGFW вы можете активировать и обновить лицензию, а также проверить срок ее действия
в онлайн-режиме
. Если доступ к серверу лицензирования отсутствует, вы можете
активировать лицензию офлайн
Базовая лицензия
Лицензирование UserGate NGFW осуществляется по параметрам производительности и зависит:
от типа аппаратной платформы (для программно-аппаратного комплекса);
количества поддерживаемых ядер виртуальной машины (для виртуального образа).
При попытке регистрации некорректного оборудования с помощью ключа с ограничением по производительности появится ошибка: «Введенный ПИН-код выписан для другого устройства UserGate, или конфигурация сервера не соответствует лицензированным характеристикам, например, увеличено число ядер процессора».
Примечание
Если виртуальная машина зарегистрирована с помощью корректного ключа, а в дальнейшем в нее будут добавлены дополнительные ядра, то активным в виртуальной машине будет только разрешенное лицензией количество ядер.
Базовая лицензия на продукт является бессрочной. В базовую лицензию UserGate NGFW включена подписка на сервис обновления (SU) сроком на один год, по истечении первого года ее необходимо продлить.
Дополнительные подписки и модули
Дополнительно лицензируются следующие подписки и модули UserGate NGFW.
Примечание
Дополнительная установка модулей на стороне пользователя не требуется. Активация основного программного обеспечения выполняется пользователем с помощью лицензионного ключа после оплаты лицензии. Дополнительные программные модули подключаются в рамках действующей подписки на основное программное обеспечение после их оплаты. Для этого сотрудники UserGate добавляют соответствующие модули в лицензионный ключ с помощью внутренней системы лицензирования.
Подписки и модули
Описание
Security Updates (SU)
Подписка SU предоставляет доступ к сервису обновлений UserGate NGFW.
Подписка дает право на получение обновлений:
программного обеспечения UserGate NGFW;
системных библиотек, включая сигнатуры системы обнаружения вторжений (IPS) и сигнатуры приложений (L7).
Подписка сроком на один год включена в базовую лицензию.
После окончания срока действия подписки:
базовые функции UserGate NGFW продолжают работать без ограничений;
обновление программного обеспечения прекращается. При необходимости можно загрузить и установить только ту версию ПО, которая была актуальна на момент окончания срока действия подписки;
обновление системных библиотек, а также сигнатур системы обнаружения вторжений и приложений прекращается. Ранее полученные библиотеки и сигнатуры продолжают использоваться.
Для возобновления получения обновлений необходимо продлить подписку SU
Advanced Threat Protection (ATP)
Подписка на модуль, расширяющий функциональные возможности UserGate NGFW.
Подписка предоставляет:
обновляемую базу категорий сайтов для URL-фильтрации;
обновляемые URL-списки, включая список фишинговых сайтов, белый и черный списки UserGate, а также списки запрещенных сайтов Роскомнадзора;
морфологические словари;
сервис веб-безопасности, используемый для блокировки рекламы, приложений социальных сетей и выполнения безопасного поиска.
Подписку можно оформить на период от 1 до 5 лет при единовременной закупке.
Для работы модуля ATP требуется также действующая подписка SU.
После окончания срока действия подписки:
сервис веб-безопасности становится недоступен;
прекращается фильтрация по категориям сайтов и морфологическим словарям;
ранее загруженные URL-списки продолжают использоваться без получения обновлений.
Для возобновления получения обновлений и работы сервисов необходимо продлить подписку
Mail security
Подписка на антиспам-модуль UserGate для проверки почтового трафика.
Модуль обеспечивает фильтрацию электронной почты на основе анализа содержимого сообщений.
Подписку можно оформить на период от 1 до 5 лет при единовременной закупке.
Для работы антиспам-модуля UserGate требуется также действующая подписка SU.
После окончания срока действия подписки фильтрация почтового трафика прекращается.
Для возобновления работы необходимо продлить подписку
Потоковый антивирус UserGate (Stream Antivirus)
Подписка на потоковый антивирус UserGate (Stream Antivirus) для защиты корпоративных сетей от вредоносного программного обеспечения.
Подписку можно оформить на период от 1 до 5 лет при единовременной закупке.
Для работы потокового антивируса UserGate требуется также действующая подписка SU
По истечении срока действия подписки антивирус перестает работать.
Для возобновления работы необходимо продлить подписку
Cluster
Модуль обеспечивает работу UserGate NGFW в режиме кластера. При приобретении нескольких устройств UserGate NGFW для работы в кластере дополнительно бесплатно предоставляется лицензия на количество узлов, входящих в кластер.
Срок действия лицензии на модуль не ограничен
Онлайн-лицензирование
Для активации лицензии используется лицензионный ключ, который может быть предоставлен одним из следующих способов:
на бумажном носителе;
в электронном виде — по электронной почте, через уведомление в личном кабинете пользователя или другим удобным способом.
При активации, проверке и обновлении лицензии UserGate NGFW подключается к серверу лицензирования и передает номер версии ПО UserGate, лицензионный ключ, название продукта и модель устройства. В ответ продукт получает данные о сроке действия лицензии и поддерживаемых модулях.

Далее

Проверка срока действия лицензии
Автоматическая проверка срока действия лицензии выполняется раз в сутки, ее результаты отображаются в журнале событий UserGate NGFW. По окончании проверки отключаются те модули, срок поддержки которых истек, и подключаются вновь доступные.
Если в ходе проверки не удается получить доступ к серверу лицензирования, выполняется 14 попыток подключения к серверу с интервалом в 2 минуты. При неуспешных попытках проверка приостанавливается на сутки, после чего попытки повторяются. Если за это время истечет срок действия лицензии на один из модулей, модуль будет отключен.
Вы также можете запускать проверку срока действия лицензии вручную. Действие доступно в разделе
Дашборды
в виджете
Лицензия
по ссылке
Проверить лицензию
Обновление лицензии
Важно!
Лицензионные ключи версий продукта 6 и 7 несовместимы. При переходе с более низких версий на версию 7 необходимо запросить новый ключ у вашего менеджера UserGate и обновить лицензию.
Важно!
При обновлении лицензии в UserGate NGFW будут принудительно сброшены все установленные сессии, а также будут перезапущены правила межсетевого экрана.

Офлайн-активация лицензии
Офлайн-активация лицензий необходима для устройств UserGate, находящихся в изолированной сети без доступа к интернету и без возможности активации через прокси-сервер.
Процесс офлайн-лицензирования включает следующие этапы:
1. Генерация запроса — создание на лицензируемом устройстве файла запроса для офлайн-активации.
2. Активация запроса — обработка сгенерированного файла запроса с помощью сервиса офлайн-активации ПИН-кодов.
3. Применение лицензии — загрузка активированного файла обратно на лицензируемое устройство.
Генерация запроса
Чтобы сгенерировать файл запроса для офлайн-активации лицензии:
1. Зайдите с помощью веб-браузера на лицензируемое устройство по следующему адресу:
https://<IP-адрес устройства>:8001?features=offline-reg
2. В веб-консоли устройства перейдите в раздел
Дашборды
3. В виджете
Лицензия
нажмите
Нет лицензии
4. В окне активации устройства нажмите
Начать активацию в автономном режиме
5. Введите ПИН-код устройства и скачайте сгенерированный файл запроса для офлайн-активации.
Активация запроса
С компьютера, имеющего доступ в интернет, обратитесь
в сервис офлайн-активации
(для входа в сервис потребуется авторизация в Едином центре авторизации) и активируйте сгенерированный файл запроса.
Применение лицензии
Загрузите активированный файл на лицензируемое устройство. Для этого:
1. В разделе
Дашборды
лицензируемого устройства в виджете
Лицензия
откройте окно офлайн-активации.
2. Выберите
Завершить активацию в автономном режиме
3. Укажите активированный файл, полученный в сервисе офлайн-активации.
Процесс лицензирования завершен.
