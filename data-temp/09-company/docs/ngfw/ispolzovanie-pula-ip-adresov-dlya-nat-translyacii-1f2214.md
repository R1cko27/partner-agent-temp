# Использование пула IP-адресов для NAT трансляции

Technology: Networking
Вопрос
Как правильно использовать пул IP адресов для NAT трансляции?
Ответ
В настройках правила типа
NAT
укажите пул IP-адресов в виде диапазона адресов, которые будут использоваться для замены адреса источника при подмене адресов пакетов (поле
SNAT IP
). Например, 10.10.0.2-10.10.0.10.
