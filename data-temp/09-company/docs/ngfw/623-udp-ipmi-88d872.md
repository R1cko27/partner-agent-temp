# 623(UDP) - IPMI

Вопрос
Уязвимость:
Найден логин и хэш пароля пользователя IPMI
ID: 8312
CVE: CVE-2013-4786
Краткое описание:
Был подобран логин и получен SHA-1 хэш пароля учетной записи IPMI. Если пароль недостаточно сложный, его
можно восстановить с помощью общедоступных утилит.
Ответ
Функционал модуля IPMI опционален, требуется только для подключения из локальной сети организации. Не рекомендуется публиковать доступ к данному интерфейсу во внешнюю сеть, где существуют риски эксплуатации данной уязвимости.
Слабый криптографический ключ
Обнаружение уязвимости типа CVE-2002-20001 при сканировании NGFW...
