# Обновление ПО кластера UserGate NGFW

Для корректного обновления кластера конфигурации необходимо, чтобы все узлы были включены и доступны на момент обновления первого узла.
Важно!
Перед обновлением рекомендуется создать резервную копию устройства, которая позволит восстановить предыдущее состояние в случае возникновения каких-либо проблем во время применения обновлений.
Обновление ПО кластера UserGate NGFW рекомендуется выполнять в следующем порядке:
1. Начните обновление с резервного узла кластера отказоустойчивости.
Примечание
После обновления на узлах кластера будет установлено ПО разных версий, поэтому узлы будут отображаться в кластере конфигурации как недоступные. После обновления всех узлов до одной версии кластер соберётся. Перевод роли мастера в кластере отказоустойчивости будет доступен.
2. В случае успешного обновления резервного узла назначьте его мастер-узлом и проверьте основные используемые функции. При отсутствии проблем произведите обновление узла, который был мастером.
Обновление может занять довольно длительное время, рекомендуется планировать установку обновлений с учетом возможного времени простоя системы. Во время обновления устройство может несколько раз перезагружаться. Как правило, после первой перезагрузки происходит установка обновления, в это время в CLI доступен ограниченный набор команд, веб-интерфейс недоступен. После установки обновлений устройство также будет перезагружено.
Примечание
Не вносите изменения в конфигурацию во время обновления кластера во избежание последующих проблем в синхронизации узлов.
