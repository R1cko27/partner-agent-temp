# Лицензирование UserGate LogAn

Содержание:
Documentation:
Для использования UserGate Log Analyzer (UserGate LogAn) необходима
базовая лицензия
, которая предоставляется доступ к основным функциям устройства. Чтобы получать обновления UserGate LogAn и использовать его расширенные функции, нужны
дополнительные лицензии
В веб-консоли UserGate LogAn вы можете активировать и обновить лицензию, а также проверить срок ее действия
в онлайн-режиме
. Если доступ к серверу лицензирования отсутствует, возможна
активация лицензии офлайн
Базовая лицензия
Базовая лицензия UserGate LogAn является бессрочной. В нее включена годовая подписка Security Updates, которая обеспечивает обновления программного обеспечения в течение первого года. По истечении этого срока подписку необходимо продлить для продолжения получения обновлений.
Дополнительные лицензии
Для расширения функциональности доступны следующие подписки и модули UserGate LogAn.
Подписки и модули
Описание
Security Updates (SU)
Подписка предоставляет доступ к сервису обновления UserGate LogAn и дает право на получение обновлений программного обеспечения (ПО).
Срок действия подписки — 1 год. По окончании этого срока последняя установленная версия ПО остается работоспособной без возможности обновления
Сенсоры
Модуль определяет количество сенсоров, от которых UserGate LogAn может получать данные. Срок действия лицензии на модуль — 1 год, по истечении которого требуется продление.
Каждый узел кластера UserGate NGFW или uDCFW передаёт собственный поток журналов и учитывается как отдельный сенсор: для кластера из N узлов требуется N сенсоров
Cluster
Модуль доступен начиная с версии 7.3.0 и обеспечивает возможность работы устройств UserGate LogAn в режиме кластера.
Срок действия лицензии на модуль не ограничен
Онлайн-лицензирование
При активации, проверке и обновлении лицензии UserGate LogAn подключается к серверу лицензирования
https://reg2.usergate.com
и передает номер версии ПО, лицензионный ключ, название и модель устройства. В ответ UserGate LogAn получает данные о сроке действия лицензии и поддерживаемых модулях.

Проверка лицензии
Автоматическая проверка срока действия лицензии выполняется раз в сутки, ее результаты отображаются в журнале событий UserGate LogAn. По окончании проверки отключаются те модули, срок поддержки которых истек, и подключаются вновь доступные.
Если во время проверки не удается получить доступ к серверу лицензирования, выполняется 14 попыток подключения к серверу с интервалом в 2 минуты. При неуспешных попытках проверка приостанавливается на сутки, после чего попытки повторяются. Если за это время истечет срок действия лицензии на один из модулей, модуль будет отключен.
