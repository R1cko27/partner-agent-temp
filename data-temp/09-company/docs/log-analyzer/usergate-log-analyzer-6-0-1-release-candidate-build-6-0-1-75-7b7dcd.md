# UserGate Log Analyzer 6.0.1 Release Candidate (build 6.0.1.7588RC, 17/08/2020).

Release Notes:
Новые возможности
UserGate Log Analyzer позволяет собирать информацию с нескольких устройств МЭ UserGate, обеспечивая единую точку анализа информации.
Позволяет собирать информацию со сторонних систем, поддерживающих работу по протоколу SNMP v2 и v3.
Позволяет создавать собственные кастомизированные отчеты.
Совместим с UserGate 6.0.1 Release Candidate.
