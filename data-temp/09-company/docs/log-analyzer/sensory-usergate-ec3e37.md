# Сенсоры UserGate

Содержание:
Documentation:
Вы можете настраивать интеграцию UserGate Log Analyzer с межсетевыми экранами UserGate NGFW (далее также — сенсоры UserGate). Для подключенных сенсоров это позволяет использовать UserGate Log Analyzer в качестве базы данных журналов, в которой выполняется их хранение и последующая обработка.
При первоначальном сетевом взаимодействии UserGate Log Analyzer обменивается с сенсорами UserGate ключами шифрования и устанавливает канал управления (порты TCP 9713 и TCP 2023). Далее сенсоры передают данные журналов на сервер UserGate Log Analyzer (порт TCP 22711) и данные о своем состоянии по протоколу SNMP (порт UDP 161). Для SNMP-мониторинга на каждом сенсоре UserGate автоматически создается соответствующее правило. Красный — соединение между серверами UserGate NGFW и UserGate Log Analyzer не установлено, сенсор отключен или недоступен.
