# Подключение к CLI-консоли UserGate

Подключиться к интерфейсу командной строки (Command Line Interface, CLI) UserGate можно следующими способами:
с помощью виртуальной консоли в случае использования виртуальной машины UserGate;
используя монитор (подключённый к разъёму VGA (HDMI) и клавиатуру (подключённую к разъёму USB) при наличии портов у используемого программно-аппаратного комплекса (ПАК);
с использованием последовательного порта в случае ПАК: для подключения используется терминал, позволяющий подключение через последовательный порт (например, Putty для Windows или minicom для Linux). Параметры подключения: 115200 8n1;
через порт управления IPMI (Intelligent Platform Management Interface) в случае аппаратных платформ UserGate модели D, E и F. Подробнее о настройке читайте
Удалённое управление с помощью IPMI
по протоколу SSH. Данный способ подходит и для виртуальных машин, и для ПАК. Подключение по SSH доступно только после окончания загрузки системы, соответственно, раздел системных утилит (резервное копирование, восстановление и т.п.) недоступны. Подключение производится с использованием порта 2200; команда для подключения:
ssh Admin@UserGateIP -p 2200
где UserGateIP — IP-адрес интерфейса UserGate, через который производится подключение. Интерфейс должен принадлежать зоне, на которой разрешён сервис
CLI по SSH
(по умолчанию сервис разрешён только на зоне Management).
Для входа используются логин / пароль администратора с корневым профилем или профилем, имеющим разрешения для доступа в CLI. В случае, если устройство UserGate не прошло первоначальную инициализацию, то используйте логин / пароль —
Admin
usergate
(в более ранних релизах использовалась комбинация Admin / utm).
