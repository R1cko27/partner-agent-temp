# Обновление ПО UserGate

Содержание:
Команда UserGate постоянно работает над улучшением качества своего программного обеспечения и предлагает обновления продуктов UserGate в рамках подписки на модуль лицензии Security Update.
Обновление ПО
При наличии обновлений в разделе
Управление устройством ➜ Операции с сервером
отобразится соответствующее оповещение. Обновление продукта может занять довольно длительное время, рекомендуется планировать установку обновлений с учетом возможного времени простоя UserGate.
Порядок установки обновлений:
1. Создайте резервную копию устройства. Наличие резервной копии позволит восстановить предыдущее состояние устройства в случае возникновения каких-либо проблем во время применения обновлений.
2. Установите обновление. В разделе
Управление устройством
при наличии оповещения
Доступны новые обновления
нажмите
Установить сейчас
. Система установит скачанные обновления, по окончании установки устройство будет перезагружено.
Важно!
Для корректного обновления кластера конфигурации необходимо, чтобы все узлы были включены и доступны на момент обновления первого узла.

Примечание
Рекомендуется создать резервную копию состояния UserGate, которая позволит восстановить предыдущее состояние устройства в случае возникновения каких-либо проблем во время применения обновлений.
Обновление ПО
Для установки обновлений на устройство UserGate:
В веб-консоли устройства на вкладке
Настройки
перейдите в раздел
UserGate ➜ Настройки ➜ Центр обновлений ➜ Обновление ПО ➜ Обновление
и нажмите
Проверить обновления
Если имеются обновления, они отобразятся в открывшемся окне проверки обновлений. Выберите нужную версию обновления и нажмите
Скачать
Когда обновление будет скачано на устройство, запустите установку обновления. При установке обновления можно задать точку восстановления устройства.
Обновления библиотек устанавливаются аналогичным образом через подраздел
Обновления библиотек
, или с помощью настройки автоматического обновления.
Подробнее об опциях обновления в версиях ПО 7.x — в разделе «
Общие настройки
» Руководства администратора.
