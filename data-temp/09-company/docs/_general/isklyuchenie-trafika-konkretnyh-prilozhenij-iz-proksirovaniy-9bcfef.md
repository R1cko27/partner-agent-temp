# Исключение трафика конкретных приложений из проксирования и инспектирования

Задача
Некоторые приложения некорректно работают при использовании устройств MITM. Требуется исключить их из проксирования и инспектирования.
Решение
Данная проблема решается путем исключения трафика проблемных приложений из проксирования и SSL инспектирования, для этого необходимо:
Создать список URL, содержащий доменные адреса, к которым подключаются проблемные сервисы.
Настроить правило captive-портала с действием "Не использовать аутентификацию" и указать созданный список URL. Правило необходимо поместить выше правила captive-портала, предназначенного для авторизации.
Настроить SSL-инспектирование с действием "Не расшифровывать" для созданного списка URL. Правило следует поместить выше правила расшифровки.
Настроить разрешающее правило контентной фильтрации для созданного списка URL и поместить его выше остальных правил.
Журналирование для всех перечисленных правил нужно выключить.
При включении DNS-фильтрации начинают блокироваться разрешенные...
Взаимодействие правил reverse-прокси, DNAT и межсетевого экрана
