18.11.2026
Уязвимость высокого уровня опасности, связанная с переполнением динамической памяти в Oracle Java SE и Graal VM: CVE-2026-114938
Уязвимость CVE-2026-114938 (неофициальное название — Java4Shell) обнаружена в продуктах Oracle Java SE, Oracle GraalVM for JDK и Oracle GraalVM Enterprise Edition; затронут компонент Compiler. Причина возникновения — переполнение динамической памяти (heap-based buffer overflow, CWE-122).
16.11.2026
Критически опасная уязвимость удаленного выполнения команд во FreeSWITCH: CVE-2026-116779
Уязвимость SIP2Shell (CVE-2026-116779) обнаружена во FreeSWITCH от SignalWire. Она возникает в функции sofia_presence_handle_sip_i_message(), которая при обработке входящего SIP-сообщения MESSAGE интерпретирует часть значения заголовка «To» до символа «+» как селектор протокола чата.
23.10.2026
Критически опасные уязвимости удаленного выполнения кода в ядре PHP: CVE-2026-109618, CVE-2026-109619
В ядре языка PHP обнаружены две критически опасные уязвимости удаленного выполнения кода (RCE) — CVE-2026-109618 и CVE-2026-109619. Уязвимости получили общее название PHP2Shell и связаны с ошибками управления памятью в ядре интерпретатора веб-запросов.
07.10.2026
Новая сигнатура UserGate для uNGFW и uWAF, направленная против атак с использованием уязвимости CVE-2026-21589 в продуктах Atlassian Data Center
Уязвимость связана с недостаточной проверкой пути в HTTP-запросе и позволяет удаленному злоумышленнику без аутентификации прочитать отдельные файлы внутри корневого каталога веб-приложения Atlassian Data Center.
23.09.2026
Критически опасная уязвимость обхода пути в нескольких продуктах Check Point: CVE-2026-93616
Уязвимость обхода пути (path traversal) найдена в продуктах Check Point в модуле обновления Upgrade Tools. Из-за недостаточной валидации в функции импорта злоумышленник может загружать и исполнять произвольные файлы.
27.08.2026
Новая сигнатура UserGate для uNGFW и uWAF, направленная против атак с использованием уязвимости CVE-2026-75604 в Next.js
Уязвимость позволяет злоумышленнику получить доступ к чувствительным файлам на сервере Next.js, работающем на Windows. Эта уязвимость может быть использована для кражи серверной конфигурации, что, в свою очередь, может привести к удаленному выполнению кода (RCE) на сервере.
