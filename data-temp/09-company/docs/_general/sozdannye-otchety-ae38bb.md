# Созданные отчеты

Documentation:
В разделе
Созданные отчеты
хранятся все полученные отчеты. Отчеты создаются в формате pdf или csv. Для каждого отчета указывается название отчета, которое совпадает с названием правила отчета, которое было использовано для создания данного отчета, время создания отчета и размер отчета.
Для скачивания отчета необходимо использовать кнопку
Скачать
, для удаления —
Удалить
Время хранения готовых отчетов (ротация) настраивается по нажатию на кнопку
Настроить
. Значение по умолчанию — 60 дней.
