# Полосы пропускания

Элемент библиотеки
Полоса пропускания
определяет скорость передачи данных, которую вы можете в дальнейшем использовать в правилах управления полосой пропускания. Подробнее о правилах управления полосой пропускания — в разделе «
Пропускная способность
Первоначальный список поставляется вместе с продуктом. Вы можете добавлять необходимые элементы в процессе работы. Для добавления новой полосы пропускания необходимо выполнить следующие шаги:
1. Создайте полосу пропускания. В разделе
Настройки ➜ Библиотеки ➜ Полосы
пропускания нажмите
Добавить
, задайте название и описание полосы пропускания.
2. Укажите скорость полы пропускания в Кбит/сек.
3. Укажите значение DSCP для QoS. Это опциональный параметр. Если установлен, будет прописываться в каждый IP-пакет. Диапазон от 0 до 63.
