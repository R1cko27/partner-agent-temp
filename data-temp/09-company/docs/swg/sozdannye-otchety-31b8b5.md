# Созданные отчеты

Все созданные отчеты хранятся в разделе
Журналы и отчеты ➜ Отчеты ➜ Созданные отчеты
. Отчеты создаются в формате PDF или CSV. Для каждого отчета указывается название отчета, которое совпадает с названием правила отчета, которое было использовано для создания данного отчета, время создания отчета и размер отчета.
Для скачивания отчета нажмите на файл с созданным отчетом, для удаления —
Удалить
Для настройки времени хранения готовых отчетов (ротации) нажмите
Настроить
. Значение по умолчанию — 60 дней.
