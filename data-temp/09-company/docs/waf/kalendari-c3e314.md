# Календари

Календари позволяют создать временные интервалы, которые затем можно использовать в различных правилах WAF. Первоначальный список поставляется вместе с продуктом. Администратор может добавлять необходимые ему элементы в процессе работы. Для добавления нового календаря необходимо выполнить следующие шаги:
Наименование
Описание
Шаг 1.
Создать календарь.
В панели
Группы
нажать на кнопку
Добавить
, указать название календаря и его описание.
Шаг 2.
Добавить временные интервалы в календарь.
В панели
Элементы
нажать на кнопку
Добавить
и добавить интервал. Дать название интервалу и указать время.
v7.x
Списки URL
Шаблоны страниц (версия 7.5.0 и выше)
