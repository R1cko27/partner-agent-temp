# Первоначальная инициализация (Описание)

Первоначальная инициализацию UserGate WAF с использованием интерфейса командной строки можно произвести нескольким способами.
Установка как главного узла.
Для настройки UserGate WAF в качестве главного узла используется команда:
Admin@nodename# execute install master
Необходимо указать параметры:
Параметр
Описание
login
Задать логин администратора
password
Задать пароль учётной записи администратора.
Указание пароля также доступно при нажатии
Enter
после указания логина администратора; необходимо дважды ввести пароль учётной записи
v7.x
Первоначальная инициализация
Команды диагностики и мониторинга
