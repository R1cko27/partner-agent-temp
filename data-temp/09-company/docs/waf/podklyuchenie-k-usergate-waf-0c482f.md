# Подключение к UserGate WAF

Интерфейс
port0
настроен на получение IP-адреса в автоматическом режиме (DHCP) и назначен в зону
Management
. Первоначальная настройка выполняется через подключение администратора к веб-консоли через интерфейс
port0
Если нет возможности назначить адрес для Management-интерфейса в автоматическом режиме с помощью DHCP, его можно явно задать, используя CLI (Command Line Interface). Подробнее об использовании CLI — в разделе «
Интерфейс командной строки
Примечание
Если устройство не прошло первоначальную инициализацию, то для доступа к CLI необходимо использовать в качестве логина
Admin
, в качестве пароля —
usergate
Остальные интерфейсы отключены и требуют последующей настройки.
Для первоначальной настройки выполните следующие шаги:

Подключитесь к интерфейсу устройства:
При наличии DHCP-сервера
. Подключите интерфейс
port0
к сети предприятия с работающим DHCP-сервером. Включите WAF. После загрузки в консоли WAF будет указан полученный интерфейсом IP-адрес. Подключитесь к веб-консоли устройства по адресу: https://<WAF_IP_address>:8001 для дальнейшей активации продукта.
Статический IP-адрес
. Включите UserGate WAF. Используя CLI, назначьте необходимый IP-адрес на интерфейс
port0
. Произведите первоначальную инициализацию в интерфейсе командной строки или подключитесь к веб-консоли UserGate WAF по указанному адресу (он должен иметь вид: https://<WAF_IP_address>:8001).
