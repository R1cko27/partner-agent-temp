# Создание пользовательских шаблонов отчетов

Documentation:
Если в системных шаблонах отсутствуют параметры, необходимые для отчета, вы можете создать собственный шаблон и использовать его в правилах генерации этого отчета.
Чтобы создать шаблон:
1. В разделе
Журналы и отчеты ➜ Отчеты ➜ Пользовательские шаблоны
нажмите
Добавить
2. В окне настройки шаблона выполните следующее:
Укажите название и при необходимости описание шаблона.
Укажите источник, данные которого требуется использовать для создания отчета. Вы можете выбрать
один из журналов
или
список срабатываний правил аналитики
При необходимости введите
выражение на языке запросов
, по которому будут отфильтрованы данные при создании отчета.
При необходимости укажите параметр, по которому будут отсортированы записи отчета, а также направление сортировки (по возрастанию или по убыванию значений параметра).
Выбор параметра для сортировки недоступен, если указан параметр для группировки записей. В этом случае сортировка выполняется по количеству записей в каждой группе в порядке убывания.
При необходимости укажите параметр, по которому будут сгруппированы записи отчета.
Выбор параметра для группировки недоступен, если указан параметр для сортировки записей.
В блоке
Столбцы ➜ Доступно
двойным щелчком мыши выберите параметры, значения которых необходимо отображать в отчете.
Примечание
Чтобы запись отчета, содержащая массив в качестве значения параметра, была преобразована в несколько записей (по одной для каждого элемента массива), установите флажок «Разъединять записи».
3. Нажмите
Созданный шаблон отобразится в таблице
Пользовательские шаблоны
. Для использования шаблона необходимо добавить его
в правило генерации отчетов
v7.x
Шаблоны
Правила отчетов
