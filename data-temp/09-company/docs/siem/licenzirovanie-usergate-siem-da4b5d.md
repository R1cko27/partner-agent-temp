Базовая лицензия
Базовая лицензия UserGate SIEM является бессрочной. В нее включена годовая подписка Security Updates, которая обеспечивает обновления программного обеспечения и библиотеки правил нормализации в течение первого года. По истечении этого срока подписку необходимо продлить для продолжения получения обновлений.
Кроме того, базовая лицензия UserGate SIEM позволяет подключать любое количество сенсоров. При отсутствии базовой лицензии подключение сенсоров к устройству невозможно.
Лицензирование UserGate SIEM версий 7.3.0 и выше осуществляется по параметрам производительности платформы.
При активации базовой лицензии проверяются следующие параметры:
Тип аппаратной платформы
. Для устройства, поставляемого в виде программно-аппаратного комплекса, тип аппаратной платформы должен совпадать с указанным в лицензии.
Количество ядер виртуальной машины
. Для устройства, поставляемого в виде виртуального образа, количество поддерживаемых ядер процессора должно быть меньше или равно количеству ядер, разрешенному лицензией.
В случае несоответствия параметров устройства указанным в лицензии процесс активации будет завершен с ошибкой. Кроме того, если после активации лицензии в виртуальную машину будет добавлено больше ядер, чем предусмотрено базовой лицензией, устройство будет использовать только разрешенное количество ядер. Начиная с версии 7.4.0 в разделе
Дашборды
в виджете с лицензией вы можете просматривать информацию об ограничениях на количество ядер процессора.
Дополнительные лицензии
Для расширения функциональности доступны следующие подписки и модули UserGate SIEM.
Подписки и модули
Описание
Security Updates (SU)
Подписка предоставляет доступ к сервису обновления UserGate SIEM и дает право на получение обновлений:
программного обеспечения (ПО);
библиотеки правил нормализации.
Срок действия подписки — 1 год. По окончании этого срока:
последняя установленная версия ПО устройства остается работоспособной без возможности обновления;
обновление библиотеки правил нормализации прекращается
Cluster
Модуль обеспечивает возможность работы устройств UserGate SIEM в режиме кластера.
Срок действия лицензии на модуль не ограничен
SIEM Expert
Модуль предоставляет право на поддержку и обновление экспертизы UserGate:
библиотеки правил аналитики;
библиотеки команд удаленного управления устройствами UserGate.
Модуль поставляется на срок от 1 до 5 лет. По истечении этого срока скачанные библиотеки остаются работоспособными, но их обновление становится недоступным. Для возобновления обновлений необходимо продлить лицензию. Продление доступно только при наличии действующей подписки SU
Онлайн-лицензирование
При активации, проверке и обновлении лицензии UserGate SIEM подключается к серверу лицензирования
https://reg2.usergate.com
и передает номер версии ПО, лицензионный ключ, название и модель устройства. В ответ UserGate SIEM получает данные о сроке действия лицензии и поддерживаемых модулях.

Проверка лицензии
Автоматическая проверка срока действия лицензии выполняется раз в сутки, ее результаты отображаются в журнале событий UserGate SIEM. По окончании проверки отключаются те модули, срок поддержки которых истек, и подключаются вновь доступные.
Если во время проверки не удается получить доступ к серверу лицензирования, выполняется 14 попыток подключения к серверу с интервалом в 2 минуты. При неуспешных попытках проверка приостанавливается на сутки, после чего попытки повторяются. Если за это время истечет срок действия лицензии на один из модулей, модуль будет отключен.
