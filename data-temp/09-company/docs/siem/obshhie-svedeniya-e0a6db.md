# Общие сведения

Documentation:
Technology: SIEM
UserGate SIEM получает данные журналов событий безопасности
от модуля log-collector
от подключенных сенсоров
и записывает эти данные в единое хранилище для последующего анализа.
Администраторы могут управлять полученными событиями безопасности в разделе
Аналитика
. Для этого на соответствующих вкладках раздела вы можете:
настраивать правила аналитики
выполнять поиск событий по заданным параметрам
создавать действия реагирования для срабатываний правил аналитики
управлять срабатываниями правил аналитики
просматривать подробную информацию о срабатываниях правил аналитики
просматривать список процессов конечных устройств
