# Просмотр подробной информации о срабатывании

Documentation:
Technology: SIEM
В разделе
Аналитика
Подробности срабатывания
вы можете просматривать подробную информацию о каждом срабатывании правила аналитики. Для этого в блоке
Срабатывание
из выпадающего списка выберите идентификатор нужного срабатывания. Информация о срабатывании отобразится в таблице и в соответствующих блоках.
Вы можете управлять выбранным срабатыванием:
Просматривать основную информацию о срабатывании в его карточке (по кнопке
Показать
Просматривать срабатывание в таблице всех срабатываний (по кнопке
Показать срабатывания
Добавлять срабатывание в зарегистрированный ранее инцидент (по кнопке
Добавить в инцидент
). При выборе инцидента в списке вам также доступна
регистрация нового инцидента
по кнопке
Создать новый инцидент
