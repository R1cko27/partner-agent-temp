# Маршруты

Documentation:
Данный раздел позволяет указать маршрут в сеть, доступную за определенным маршрутизатором. Например, в локальной сети может быть маршрутизатор, который объединяет несколько IP-подсетей.
Для добавления маршрута необходимо выполнить следующие шаги:
Наименование
Описание
Шаг 1.
Задать название и описание данного маршрута
В разделе
Сеть
выберите в меню
Маршруты
, нажмите кнопку
Добавить
. Укажите имя для данного маршрута. Опционально можно задать описание маршрута.
Шаг 2.
Указать адрес назначения
Задайте подсеть, куда будет указывать маршрут, например, 172.16.20.0/24 или 172.16.20.5/32.
Шаг 3.
Указать шлюз
Задайте IP-адрес шлюза, через который указанная подсеть будет доступна. Этот IP-адрес должен быть доступен с сервера UserGate SIEM.
Шаг 4.
Указать интерфейс
Выберите интерфейс, через который будет добавлен маршрут. Если оставить значение
Автоматически
, UserGate SIEM сам определит интерфейс, исходя из настроек IP-адресации сетевых интерфейсов.
Шаг 5.
Указать метрику
Задайте метрику маршрута. Чем меньше метрика, тем приоритетней маршрут в данную сеть, если маршрутов несколько.
