# Первоначальная инициализация (описание)

Documentation:
Первоначальная инициализация устройства с использованием интерфейса командной строки.
Для настройки устройства используется команда:
Admin@nodename# execute install master
Необходимо указать параметры:
Параметр
Описание
login
Задать логин администратора.
password
Задать пароль учётной записи администратора.
Указание пароля также доступно при нажатии
Enter
после указания логина администратора; необходимо дважды ввести пароль учётной записи.
