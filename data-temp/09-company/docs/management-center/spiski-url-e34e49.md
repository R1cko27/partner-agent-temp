# Списки URL

Списки URL используются в правилах для устройств, подключенных к UserGate MC, в качестве черных и белых списков.
Вы можете создавать статические списки URL-адресов, которые хранятся в UserGate MC, и обновляемые, которые автоматически пополняются из файлов, размещенных на внешнем сервере.
Примечание
О добавлении обновляемого списка URL-адресов — в разделе «
Настройка обновляемых списков элементов
Чтобы создать статический URL-список:
1. В разделе
Управление областью
Общая библиотека
Списки URL
в блоке
Список
нажмите
Добавить
2. В открывшемся окне на вкладке
Общие
укажите параметры URL-списка:
название и при необходимости описание;
содержимое:
Чувствительный к регистру
— URL-адреса с учетом регистра (для контентной фильтрации);
Нечувствительный к регистру
— URL-адреса без учета регистра (для контентной фильтрации);
Домен
—  доменные имена (для DNS-фильтрации).
3. Нажмите
4. Выберите добавленный URL-список.
5. В блоке
Элементы списка
нажмите
Добавить
6. В открывшемся окне укажите URL-адрес или доменное имя.
Примечание
При указании URL-адреса или доменного имени вы можете использовать символы
(любое количество произвольных символов),
(начало строки),
(конец строки). Не допускается использование символов
Например:
^example.domain.com$
— доменное имя без поддоменов (с любыми протоколами и путями);
^http://domain.com/example$
— только указанный URL-адрес;
domain.com
— доменное имя и все его поддомены (с любыми протоколами и путями);
*example*
— любые URL-адреса или доменные имена, содержащие
example
^example.domain.com/$
— некорректное значение (символ
требует указания протокола).
7. Нажмите
8. Для добавления других URL-адресов и доменных имен повторите шаги 5–7 инструкции.
Добавленные URL-адреса и доменные имена отобразятся в блоке
URL
для выбранного списка.
IP-адреса
