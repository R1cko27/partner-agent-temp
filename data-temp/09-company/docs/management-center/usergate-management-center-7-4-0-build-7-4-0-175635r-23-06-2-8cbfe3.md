# UserGate Management Center 7.4.0(build 7.4.0.175635R, 23/06/2025)

Содержание:
Release Notes:
Статус
Бета
Внимание!
Версия в стадии бета-тестирования и не рекомендуется для массовой установки в производственную инфраструктуру (production). Задача этой сборки: проверка в "боевых условиях" у лояльных клиентов, сбор обратной связи и выявление потенциальных недостатков на ранней стадии.
Новые возможности
№ задачи
Описание
SUM-4874
Обновлены стили Web интерфейса.
SUM-12977
Добавлены устройства и шаблоны SIEM (только с разделом general settings).
SUM-16298
Добавлена возможность исключений из правил NAT.
SUM-17897
Добавлена возможность проверки категорий сайтов в шаблонах NGFW на МС через настройки вышестоящего прокси для проверки лицензии и обновлений.
SUM-4832
Добавлена возможность передачи объектов (списки,библиотеки) между шаблонами.
SUM-5713
Добавлена возможность использовать в правилах каскадного прокси пользователей и групп пользователей в качестве условия.
Улучшения и оптимизации
№ задачи
Описание
SUM-14883
Изменена логика работы при отключении NGFW от МС. При отключении от MC убирается префикс [MC] у всех объектов NGFW, если есть дубликат по имени, то префикс остается.
SUM-16644
Оптимизирован расход ресурсов CPU.
