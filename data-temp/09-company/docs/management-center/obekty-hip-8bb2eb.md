# Объекты HIP

Documentation:
Объекты HIP позволяют настроить критерии соответствия для конечных устройств, к которым необходимо применить политики.
Для добавления объекта необходимо указать:
Наименование
Описание
Включено
Включение/отключение использования объекта.
Название
Название объекта HIP.
Описание
Описание объекта HIP (опционально).
Версия ОС
Версия операционной системы устройства пользователя.
Версия UserGate Client
Версия ПО UserGate Client.
Проверка на соответствие статуса:
Антивирус
. Проверка соответствия антивирусного ПО на устройстве пользователя.
Включено
: проверка статуса ПО;
Базы антивируса обновлены
: да, нет, не проверять;
Версия
ПО;

: производитель и название продукта.

Процессы

Запущенные службы
Проверка служб, запущенных на конечном устройстве.
Ключи реестра
Ключ реестра Microsoft Windows - каталог, в котором хранятся настройки и параметры операционной системы.
Поддерживаются следующие типы параметров реестра:
REG_SZ
: строка Unicode или ANSI с нулевым символом в конце;
REG_BINARY
: двоичные данные в любой форме;
REG_DWORD
: 32-разрядное число.
Доступно использование следующих ключей реестра:
HKEY_LOCAL_MACHINE
(аббревиатура: local_machine, hklm);
HKEY_USERS
(аббревиатура: users, hku).
Важно!
При указании пути также доступно использование аббревиатуры корневого каталога реестр. Путь указывается с использованием обратного слэша (
), например, \hklm.
Описание ключей реестра читайте в документации Microsoft (
https://docs.microsoft.com/ru-ru/troubleshoot/developer/webapps/iis/general/use-registry-keys
