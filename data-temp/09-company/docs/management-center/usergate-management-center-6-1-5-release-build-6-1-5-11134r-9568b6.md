# UserGate Management Center 6.1.5 Release (build 6.1.5.11134R, 11/02/2022)

Содержание:
Release Notes:
Новые возможности
Добавлена возможность указания в UGMC одинаковых IP-адресов для шлюзов для разных VRF.
Добавлены дополнительные проверки на корректность при импорте списков в UGMC.
Добавлена проверка, запрещающая создавать маршрут 0.0.0.0/0 в шаблонах конфигурации NGFW.
Добавлена возможность контекстного хелпа по расширенному поиску в правилах в консоли.
Добавлена поддержка RAID-контроллера LSI 9361-16i.
Улучшения и оптимизации
Улучшено отображение страницы авторизации администратора при разных размерах окна браузера.
Улучшена процедура управления локальными пользователями, созданными из UGMC.
Улучшена работа с обновлением UGOS при изменении канала обновлений.
Исправления
Исправлена ошибка, приводящая к невозможности давать права на доступ к странице Диагностика и мониторинг в профилях доступа.
Исправлена проблема, при которой правило МЭ с указанной пользовательской группой приложений, не корректно работает.
Исправлена проблема присвоения некорректного профиля доступа администратору при наличии различных профилей, назначенных на пользователя и на группу, в которую входит этот пользователь.
Исправлена проблема создания группы приложений.
Исправлена проблема, связанная с невозможностью добавить URL вида //example.com в список URL.
Исправлена проблема отображения некорректного IP-адреса администратора в журнале событий.
Исправлена проблема идентификации на UserGate локального пользователя с заданным IP-адресом и созданного в UGMC.
Исправлена проблема с невозможностью входа администратора в CLI SSH, если его пароль содержит спецсимволы.
Исправлена проблема, при которой несколько шлюзов могли быть назначены как шлюзы по умолчанию.
Исправлена проблема настройки защиты от спуфинга на зонах.
Исправлена проблема, при которой обновления UGOS не доступны из бета-ветки обновлений.
Исправлены ошибки, возникающие при обновлении базы блокировщика рекламы через UGMC.
