# Управление списком устройств

Documentation:

содержит список устройств в управляемой области. В этом списке вы можете:

Удалять устройства по кнопке

Просматривать параметры устройства
Изменять параметры устройства по кнопке
Редактировать

Блокировать
Разблокировать
соответственно.
Переподключать конечное устройство по кнопке

. В результате будет сгенерирован новый код для подключения к UserGate MC. Это может понадобиться, например, при переустановке UserGate Client на конечном устройстве.

Кроме того, вы можете настраивать отображение устройств в списке с помощью следующих фильтров:
— все устройства (фильтр по умолчанию).
Включенные
Выключенные
— устройства в выбранном состоянии.
Онлайн
— для привязанных конечных устройств установлено соединение с сервером UserGate MC.
Офлайн
— для привязанных конечных устройств не установлено соединение с сервером UserGate MC.
Не привязанные
— устройства, к которым не привязаны конечные устройства.
Консистентные устройства
— устройства, к которым привязаны конечные устройства с параметрами, синхронизированными с конфигурацией параметров группы шаблонов.
Неконсистентные устройства
— устройства, к которым привязаны конечные устройства с параметрами, не синхронизированными с конфигурацией параметров группы шаблонов.
Подходящие под HIP-профиль устройства
— устройства, к которым привязаны конечные устройства, соответствующие
требованиям проверки безопасности
Не подходящие под HIP-профиль устройства
— устройства, к которым привязаны конечные устройства, не соответствующие
требованиям проверки безопасности
Вы также можете управлять синхронизацией параметров между группой шаблонов и конечными устройствами. В процессе синхронизации к управляемому устройству применяется конфигурация параметров группы шаблонов.
Доступны ручной и автоматический режимы синхронизации. Вручную вы можете запускать синхронизацию сразу для всех управляемых устройств (по кнопке
Запустить полную синхронизацию
) или только для выбранных (по кнопке
Запросить синхронизацию
В автоматическом режиме параметры управляемого устройства синхронизируются с конфигурацией параметров группы шаблонов при каждом ее изменении. Кроме того, при автоматической синхронизации подключенное конечное устройство отправляет UserGate MC сведения о своем состоянии каждые 20 секунд, в результате чего обновляется время последней успешной синхронизации для устройства.
При необходимости синхронизацию можно отключить. Это может понадобиться, например, если нужно одновременно изменить параметры нескольких шаблонов группы. В этом случае вы можете применить сразу все внесенные изменения в таблице
Устройства
, выполнив синхронизацию вручную по кнопке
Синхронизировать сейчас
Просмотр параметров устройства
Для каждого устройства в списке отображаются следующие параметры.
Параметр
Описание
Название
Название устройства
Версия ОС
Версия ОС Windows, установленной на конечном устройстве
Версия
Версия UserGate Client, установленного на конечном устройстве
Последнее подключение
Дата и время последнего подключения конечного устройства
Телеметрия
Информация о конечном устройстве. Например, IP-адрес, NetBIOS-имя, время последнего подключения к UserGate MC и имя пользователя, выполнившего вход в систему
Мониторинг
Статус синхронизации параметров между конечным устройством и примененной группой шаблонов. При возникновении ошибки синхронизации доступен просмотр отчета по кнопке
Показать отчет
Примечание
Ошибка синхронизации не влияет на работу правил межсетевого экрана: конечное устройство использует последнюю успешно примененную конфигурацию. Также остается доступным управление сервисами, процессами и запросами в реестр Windows.
Доступен просмотр подробной информации о конечном устройстве по ссылке
Информация о конечном устройстве
Группы шаблонов
Примененная группа шаблонов
HIP-профили
, которые используются в правилах межсетевого экрана. Соответствие конечного устройства профилю обозначается цветовым индикатором:
Зеленый — устройство соответствует профилю.
Красный — устройство не соответствует профилю. При этом доступен просмотр отчета по кнопке
Посмотреть отчет
. В отчете отображаются время последнего получения данных, название HIP-профиля и HIP-объектов, тип HIP-объекта и критерий, по которому выявлено несоответствие
Устройства LogAn/SIEM
При подключенном
внешнем сервере журналирования
отображается его название
Время последней синхронизации

Дата лицензирования

Лицензирован

Просмотр подробной информации о конечном устройстве
В разделе
Управление областью
Конечные устройства
Устройства

Мониторинг
нажмите
Информация о конечном устройстве
. Откроется окно со следующими вкладками.
Вкладка
Описание
Общие
Сведения о конечном устройстве (имя компьютера, версия и тип ОС, версия UserGate Client, IP-адрес, время загрузки системы и текущее время на устройстве) и о пользователе, выполнившем вход в систему (фотография, имя, статус, тип учетной записи — локальная или доменная, телефон, электронная почта)
Производительность
В виде графика и таблиц отображаются следующие показатели производительности конечного устройства:
загрузка центрального процессора;
загрузка процессора процессом UserGate Client;
использование виртуальной памяти;
использование оперативной памяти;
объем памяти, используемый UserGate Client;
информация о дисках (размер, тип, производительность)
Безопасность
Информация о состоянии межсетевого экрана, антивируса, центра обеспечения безопасности Windows, а также о шифровании дисков (BitLocker)
USB-устройства
Список подключенных USB-устройств
Элементы автозагрузки
Список приложений, для которых настроен автоматический запуск при входе в систему
Процессы
Список запущенных процессов.
Вы можете принудительно завершить процесс по кнопке
Завершить процесс
Службы
Список служб конечного устройства и их состояний.
Вы можете запустить или остановить службу с помощью кнопок
Запустить службу
Остановить службу
соответственно
Ключи реестра
Разделы реестра Windows HKEY_LOCAL_MACHINE и HKEY_USERS. При выборе ключа реестра отображаются его название, тип и значение
Программное обеспечение
Список установленных программ
Установленные обновления
Список установленных обновлений
Точки восстановления
Список доступных точек восстановления системы
Кроме того, на каждой вкладке отображаются дата и время получения данных, а также статус подключения конечного устройства:
Онлайн
— соединение между конечным устройством и сервером UserGate MC установлено, данные передаются;
Офлайн
— соединение между конечным устройством и сервером UserGate MC не установлено, данные не передаются;
Отключен
— соединение между конечным устройством и сервером UserGate MC разорвано (по кнопке
Отключить
для устройства в управляемой области), данные не передаются.
