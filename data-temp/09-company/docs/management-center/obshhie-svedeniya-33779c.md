# Общие сведения

В каждом шаблоне конфигурации управляемого устройства UserGate есть собственная библиотека элементов для настройки правил. Элементы из библиотеки шаблона можно использовать только в шаблонах конкретного типа устройства. Общая библиотека служит хранилищем нескольких типов элементов, доступных для настройки правил для любых устройств, а также позволяет просматривать изменения в свойствах этих элементов и отслеживать зависимости объектов — использование элементов в других объектах системы.
Вы можете добавлять элементы в разделы общей библиотеки, создавать их копии, редактировать и удалять.
Доступ к общей библиотеке имеют администраторы области, которым назначен профиль с соответствующим разрешением. Подробнее об этом — в разделе «
