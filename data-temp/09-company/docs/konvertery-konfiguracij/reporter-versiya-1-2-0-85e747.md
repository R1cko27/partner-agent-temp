# Репортер (версия 1.2.0)

Содержание:
Documentation:
Скачать
Репортер доступен для скачивания в личном кабинете в разделе "Скачать ПО".
Описание
Программа предназначена для преобразования конфигураций NGFW и SWG, ранее выгруженных конвертером конфигураций UserGate, в формат HTML.
Программа работает только в графическом режиме. Доступны исполняемые файлы для:
Ubuntu версии 24.04 или выше.
AstraLinux версии 1.7
AstraLinux версии 1.8
РЕД ОС версии 8.0
AltLinux рабочая станция 10 и выше.
Пока возможно преобразование конфигурации NGFW версий 7.3.0 и выше и SWG. Полная поддержка DCFW и групп шаблонов МС будет добавлена в будущем.
Преобразование конфигурации:
Скачайте архив
ug_reporter.zip
и распакуйте его. Файл
ug_reporter
сделайте исполняемым.
Репортер (файл
ug_reporter
) необходимо поместить в каталог конвертера конфигураций UserGate (
ug_ngfw_converter
). Программа работает с конфигурацией, полученной с помощью
ug_ngfw_converter
(каталог
ngfw_data
в текущей директории).
Запустите программу
ug_reporter.
Программа выполняется в графической среде. В текущей директории будет создан каталог
reports
для хранения всех преобразованных конфигураций.
Выбрать пункт "
Преобразование конфигурации NGFW, SWG
Далее программа попросит выбрать название каталога с конфигурацией, которую необходимо преобразовать.
Можно конвертировать всю конфигурацию, только выбранную группу разделов или отдельный раздел.
Можно сохранить лог в файл. Файл будет создан в выбранном каталоге конфигурации.
По окончании преобразования будет сформирован индексный файл
index.html
в каталоге
reports/NGFW/<
имя_каталога_который_вы_выбрали
В этом же каталоге будет создан файл
all_config.html
содержащий всю конфигурацию для удобной печати в PDF из браузера.
Если вы обнаружили ошибку в программе или у вас что то не получается, пожалуйста, сделайте заявку в тех.поддержку компании UserGate.
Универсальный конвертер (версия 9.28)
