# Группы приложений

В данном разделе пользователь может управлять (создавать/обновлять/удалять) группами приложений. Группы приложений могут быть использованы при настройке правил управления пропускной способности.
Для создания группы приложений:
Наименование
Описание
Шаг 1.
Создать группу.
В разделе
Библиотеки
Группы приложений
нажать на кнопку
Добавить
, указать название и, опционально, описание группы приложений.
Шаг 2.
Добавить сигнатуры приложений в группу.
На панели
Приложения
нажать
Добавить
и выбрать сигнатуры приложений для добавления в группу. Для добавления всех сигнатур приложений использовать кнопку
Добавить все
