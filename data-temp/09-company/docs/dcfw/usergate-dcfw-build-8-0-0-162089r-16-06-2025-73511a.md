# UserGate DCFW(build 8.0.0.162089R, 16/06/2025)

Release Notes:
Статус
Бета
Описание
Новый продукт UserGate Data Center Firewall (UserGate DCFW) относится к классу NGFW и предназначен для защиты ЦОДов и периметра крупных корпоративных сетей, в которых могут использоваться десятки тысяч правил межсетевого экрана (поддерживается обработка до 130 000 правил МЭ).
Новые возможности
Добавлена возможность управления DCFW из MC
Ограничения версии
В данной версии отсутствуют функции контентной фильтрации;
Поддерживается работа на платформах E1010, E3010, F8000 и F8010.
Обновление с предыдущих версий
Не применимо.
