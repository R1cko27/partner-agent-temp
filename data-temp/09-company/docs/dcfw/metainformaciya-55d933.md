# Метаинформация

Поле
.rev
предназначено для указания дополнительной информации: пользователь, который создал сигнатуру, дата создания, тип и версия сигнатуры. Поле является опциональным и не влияет на работу СОВ; может быть использовано для отслеживания изменений.
Формат поля следующий:
.rev = <date>,<version>,<status>,<author>;
где параметры имеют следующий тип данных:
<date>: целочисленный;
<version>: целочисленный;
<status>: строковый;
<author>: строковый.
