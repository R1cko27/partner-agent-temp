# Группы сервисов

В этом разделе вы можете управлять (создавать, обновлять, удалять) группами объектов сервисов. Группы сервисов могут быть использованы при настройке политик безопасности DCFW.
Для создания группы сервисов:
1. В разделе
Настройки ➜ Библиотеки ➜ Группы сервисов
в блоке
Группы сервисов
нажмите
Добавить
и укажите название и произвольное описание создаваемой группы.
2. В блоке
Элементы
нажмите
Добавить
и выберите сервисы для добавления в группу. Для добавления всех сервисов нажмите
Добавить все
v8.x
Сервисы
IP-адреса
