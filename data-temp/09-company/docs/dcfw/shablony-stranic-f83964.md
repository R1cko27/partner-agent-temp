# Шаблоны страниц

Содержание:
С помощью шаблонов страниц вы можете настраивать отображение страниц блокировки, авторизации, предупреждений и сетевых ошибок. Список шаблонов страниц, которые поставляются с UserGate DCFW, — см. в таблице ниже.

Настройка шаблона страницы блокировки
По умолчанию шаблон страницы блокировки настроен на отображение следующей информации:
Сведения о блокирующем правиле;
Сведения об угрозе;
Категория URL;
Морфологические категории;
Кнопка запроса добавления URL в белый список.
Но в HTML-коде шаблона страницы блокировки содержатся дополнительные блоки информации или интерактивных элементов, которые по умолчанию закомментированы. В режиме редактирования HTML-кода в шаблон блокировки можно добавить следующие сведения и формы:
Поле для указания причины добавления URL в белый список.
Дата блокировки.
IP-адрес пользователя, отправившего запрос, который был заблокирован.
Имя узла UserGate DCFW, заблокировавшего запрос.
Названия групп, в которых состоит пользователь.
Форма ввода логина и пароля администратора для снятия блокировки
Чтобы создать пользовательский шаблон страницы блокировки:
1. В разделе
Настройки ➜ Библиотеки ➜ Шаблоны страниц
нажмите
Добавить
и выберите
Страница блокировки
2. Выберите из списка созданный шаблон и нажмите
Экспорт
. На ПК загрузится шаблон в формате HTML-страницы.
3. Используя текстовый редактор, откройте страницу, найдите закомментированные блоки для отображения дополнительных сведений и раскомментируйте нужные.
Примечание
Не рекомендуется использовать специальные редакторы, предназначенные для редактирования HTML-файлов, поскольку они могут изменить внутреннюю структуру шаблона.
4. Импортируйте измененную страницу в созданный шаблон.
Настройка пользовательского оформления страниц
По умолчанию шаблоны страниц настроены на отображение сведений в стандартном оформлении. Вы можете использовать шаблоны в качестве основы для создания пользовательских шаблонов в собственном стиле, например в стиле вашей организации.
Чтобы настроить оформление страницы:
1. В разделе
Настройки ➜ Библиотеки ➜ Шаблоны страниц
нажмите
Добавить
и создайте шаблон страницы нужного типа.
2. Выберите из списка созданный шаблон и нажмите
Экспорт
. На ПК загрузится шаблон в формате HTML-страницы.
3. Используя текстовый редактор, откройте страницу и отредактируйте HTML-код для настройки собственного оформления.
Примечание
Не рекомендуется использовать специальные редакторы, предназначенные для редактирования HTML-файлов, поскольку они могут изменить внутреннюю структуру шаблона.
4. Импортируйте измененную страницу в созданный шаблон.
