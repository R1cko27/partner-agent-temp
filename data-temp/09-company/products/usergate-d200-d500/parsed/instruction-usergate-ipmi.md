УПРАВЛЕНИЕ С ПОМОЩЬЮ IPMI

Управление устройствами D200, D500, E1000,
E3000, F8000 с помощью IPMI

Введение

Аппаратные платформы UserGate моделей D200, D500, E1000, E3000, F8000
оснащены модулем IPMI (Intelligent Platform Management Interface), который
обеспечивает удаленное управление и мониторинг аппаратных компонентов
устройств.

IPMI функционирует независимо от операционной системы сервера. Для
доступа к функциям управления используется веб-интерфейс.

Настройка IPMI

Управление по IPMI осуществляется через Ethernet-порт Management (MGMT).
Если такой порт не обозначен, используется порт 0 (самый левый порт в ряду
Ethernet-портов).

Настройка IPMI выполняется в несколько этапов:

     1. Подключите кабель к порту управления MGMT.

     2. Войдите в веб-интерфейс:

- Убедитесь, что сетевой интерфейс вашего ПК имеет IP-адрес из
           подсети 192.168.0.0/24.

- Откройте веб-браузер и перейдите по адресу: https://
           192.168.0.100.

- Для первичного входа используйте стандартные учетные данные:

  - Логин: admin,

  - Пароль: admin.

3. Настройте сетевые параметры IPMI:

- В разделе Configuration-Network укажите:

  - IP-адрес,

  - Маску подсети,

  - Шлюз по умолчанию (если требуется).

       4. Выполните повторное подключение к веб-интерфейсу:

- Введите в браузере новый адрес: https://NEW_IP (где NEW_IP —
             адрес, заданный на предыдущем шаге).

- Сетевой адаптер ПК должен находиться в той же подсети, что и новый
             IP-адрес IPMI, или иметь к нему доступ.

       5. В разделе Configuration вы можете настроить опциональные параметры
       IPMI.

              Примечание
          Рекомендуется поменять пароль пользователю admin. Длина пароля не
          должна превышать 16 символов.

 Удаленное управление

 Для подключения к консоли аппаратной платформы подключитесь к веб-
 интерфейсу IPMI и в разделе             Remote console нажмите на кнопку Java Console.

 Для успешной работы необходимо иметь на компьютере установленное
 программное обеспечение Java. Кроме этого, в настройках безопасности Java
 необходимо указать IP-адрес, назначенный IPMI, в Exception site list в виде
 https://NEW_IP.

 Рекомендуемый браузер для работы с Java – Mozilla Firefox.
