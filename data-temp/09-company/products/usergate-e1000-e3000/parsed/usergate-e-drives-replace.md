Замена дисков на платформах E1000, E3000

Порядок замены дисков

1. Заранее подготовьте флеш-накопитель с нужной версией ПО и накопитель для
резервной копии.

2. Выключите устройство.

3. Включите устройство. При загрузке выберите пункт Support menu и сделайте
резервную копию ПО. Подробнее — в инструкции «Резервное копирование и
восстановление».

4. Демонтируйте устройство из стойки.

5. Произведите замену двух дисков согласно инструкции «Замена SSD дисков на
платформах E-серии    ».

6. Установите устройство обратно в стойку.

7. Включите устройство и создайте RAID1 согласно инструкции «         Сборка RAID1 на
SSD».

8. Установите на устройстве ПО той же версии, с которой была сделана
резервная копия. Подробнее о процедуре — в статье «Установка ПО UserGate
на аппаратных платформах C100, D200, D500, E1000, E3000, F8000          ».

9. Восстановите на устройстве ранее созданную резервную копию. Подробнее
— в инструкции «Резервное копирование и восстановление».

10. Подключите устройство к сети и проверьте его работоспособность.

Приложения

Резервное копирование и восстановление

Для создания резервной копии устройства:

## Страница 4

1. Подключитесь к консоли устройства одним из следующих способов:

- С помощью монитора и клавиатуры при наличии соответствующих
       разъемов на устройстве.

- С помощью терминала через консольный порт устройства. Для
       подключения компьютера к устройству необходим специальный
       консольный кабель или переходник USB-Serial. Запустите терминал,
       позволяющий создавать подключение через последовательный порт,
       например Putty для Windows. Установите подключение через
       последовательный порт, указав параметры подключения: 115200, 8n1.

 2. Перезагрузите устройство.

 В веб-консоли администратора в разделе Управление устройством
 ➜ Операция с сервером     нажмите Перезагрузить.

 3. Во время загрузки устройства выберите в консоли Support
 menu и затем Create backup.

 При подключении через последовательный порт загрузочное меню не
 отображается. Для выбора раздела Support menu необходимо во время
 загрузки нажимать клавишу «4». Для выбора пункта меню Create backup —
 нажать клавишу «C», затем клавишу «Enter».

       Примечание
    В версии UGOS 6.x доступно два вида резервного копирования:          Backup
    full, Backup system only. Backup system only создает полную копию только
    системного раздела устройства UserGate со всеми настройками, состоянием
    кластера и лицензией; раздел журналов не копируется.

## Страница 5

4. Создайте резервную копию.

Вставьте флеш-накопитель в USB-порт устройства. Устройство отформатирует
накопитель и сохранит на него текущее состояние системы. По окончании
процедуры устройство будет перезагружено.

      Важно!
   В версиях UGOS 7.0.x – 7.2.x диск для резервной копии должен быть заранее
   отформатирован в формате NTFS.

Для восстановления устройства из резервной копии:

1. Подключитесь к консоли устройства одним из следующих способов:

- С помощью монитора и клавиатуры при наличии соответствующих
      разъемов на устройстве.

- С помощью терминала через консольный порт устройства. Для
      подключения компьютера к устройству необходим специальный
      консольный кабель или переходник USB-Serial. Запустите терминал,
      позволяющий создавать подключение через последовательный порт,
      например Putty для Windows. Установите подключение через
      последовательный порт, указав параметры подключения: 115200, 8n1.

2. Перезагрузите устройство.

В веб-консоли администратора в разделе Управление устройством
➜ Операция с сервером     нажмите Перезагрузить.

3.  Во время загрузки устройства выберите в консоли Support
menu и затем Restore from backup.

 Замена SSD дисков на платформах E-серии

 Перед началом выполнения работ отключите все кабели питания.

 1. Выкрутите шесть винтов на крышке устройства (четыре винта по бокам и два
 винта сверху) и снимите ее сдвигом от себя.

 2. Запомните, либо сделайте снимки подключения кабелей к дискам. Отключите
 кабели SATA и кабели питания от обоих дисков.

 3. Выкрутите четыре винта на корзине для дисков.

## Страница 7

4. Аккуратно вытащите корзину с дисками. Старайтесь не повредить
расположенные рядом шлейфы.

5. Выкрутите по четыре крепежных винта на корзине для каждого диска.

6. Демонтируйте старые диски и установите новые.

7. Закрутите обратно крепежные винты для дисков.

8. Аккуратно установите корзину для дисков в устройство.

9. Подключите кабели SATA и питания обратно.

10. Установите крышку устройства и закрутите все винты.

11. Наклейте гарантийную пломбу.
