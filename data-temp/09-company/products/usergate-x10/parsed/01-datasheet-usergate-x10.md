# UserGate NGFW X10 — технические характеристики и возможности

Datasheet на русском языке. PDF: 15 страниц. Дата выпуска в PDF не указана; страница документации, с которой получен файл, обновлена 2026-09-01.

Аппаратный межсетевой экран следующего поколения для защиты объектов АСУ ТП и работы в экстремальных температурных условиях.

## Назначение и позиционирование

Для небольших организаций и филиалов, АСУ ТП.

UserGate NGFW X10 — аппаратный межсетевой экран следующего поколения для защиты объектов АСУ ТП и работы в экстремальных температурных условиях.

- Устройство стабильно работает при температуре от –40 до +60 °C и относительной влажности до 80%. Реализовано пассивное охлаждение, защита от пыли (на уровне IP30), монтаж на DIN-рейку и поддержка до 2 блоков питания AC/DC или DC/DC. Может использоваться для защиты технологических сетей (АСУ ТП): подстанций, буровых, производственных цехов, диспетчерских пунктов и т.д.
- Устройство сертифицировано ФСТЭК России по 4-му уровню доверия, требованиям к МЭ по профилю защиты А, Б и Д 4-го класса защиты, а также как СОВ уровня сети 4-го класса защиты (сертификат № 3905).

### Сетевая безопасность

#### Межсетевой экран (FW)

- Контроль состояния сессий (FW L4)
- Сценарии для реакции на события
- Счётчик срабатывания правил (rule counter)
- Журналирование начала сессии / каждого пакета

#### Контроль приложений (FW L7)

- Собственная разработка UserGate
- Контроль 1800 приложений
- Учёт российской специфики (например, 1С)
- Управление подприложениями
- Возможность создавать собственные сигнатуры (с помощью языка UASL¹)

#### Трансляция сетевых адресов (NAT)

- Source NAT, Dynamic NAT
- PAT
- NoNAT, NoDNAT
- Подмена адреса сети источника/назначения (Network mapping)

#### Контроль доступа в сеть (NAC)

- Поддержка Host Information Profile (HIP)
- Для работы нужен UserGate Client

#### Сетевой антивирус (NAV)

- Собственная разработка UserGate
- Сигнатуры от UserGate uFactor
- Запрет просмотра при обнаружении ВПО
- Запрет загрузки определённых видов файлов

#### Защита от DoS-атак

- Защита от сетевого флуда для протоколов TCP, UDP, ICMP
- Профили для защиты отдельных сервисов, протоколов и т.д.
- Настройка порога отбрасываемых пакетов
- Настройка ограничения сессий для защищаемого ресурса
- Сценарии для реакции на события
- Блокировка по географическому признаку (GeoIP)
- Журналирование начала сессии / каждого пакета

#### Система предотвращения вторжений (IPS)

- Собственная разработка UserGate
- Проверяет 100% расшифрованного SSL-трафика
- Эвристические правила и 11 000+ сигнатур известных атак
- Блокирование атак в реальном времени
- Меры защиты: обрыв соединения, блокирование адреса источника, оповещение администратора
- Возможность создавать собственные сигнатуры (с помощью языка UASL¹)
- Для каждой сигнатуры можно настроить своё действие
- Анализируются как прямые, так и обратные пакеты
- Поддерживаются профили IPS
- Опциональный пропуск проверки IPS при высокой загрузке CPU (flow control)
- Опциональная проверка части пакета TCP-сессии для снижения загрузки CPU (intelligent mode)

#### SNI-инспекция

- Для определённых пользователей и/или групп, зон и т.д.
- Календарь для применения каждого правила (дни, часы)

#### SSL-инспекция

- Инспекция TLS вплоть до TLSv1.3
- Управление min/max-версией TLS
- Блокировка самоподписанных/истекших сертификатов
- Передача расшифрованного SSL (SSL forwarding)
- Выборочная фильтрация трафика по SNI или Subject Name

#### Защита от спама (AntiSpam)

- Собственная разработка UserGate
- Проверка SMTPS, POP3S
- Блокировка SMTP по одной из баз DNSBL
- Различение возвращаемых и поддельных писем (BATV)
- Поддержка белых/чёрных списков IP-адресов
- Блокировка письма с/без уведомления
- Маркировка сообщений по результатам проверки на спам
- Блокировка по географическому признаку (GeoIP)
- Журналирование срабатывания правила

#### Виртуальные частные сети (VPN)

- Защищённая передача данных (S2S VPN): IKEv1/L2TP, IKEv2 с сертификатом (поддерживаемые алгоритмы: 3DES, AES-128, AES-192, AES-256)
- Защищённый удалённый доступ (RA VPN): IKEv1/L2TP, IKEv2 с сертификатом, IKEv2 + EAP-RADIUS (поддерживаемые алгоритмы: 3DES, AES-128, AES-192, AES-256)
- Веб-портал для удалённых/мобильных пользователей (SSL VPN)

¹ UserGate Application & Security Language.
