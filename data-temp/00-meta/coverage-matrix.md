# Матрица покрытия тем

Что уже есть в базе, чего не хватает и откуда это брать. Отметки: **есть** — подтверждено и лежит в `data/company/`; **частично** — есть общее описание, нет деталей; **нет** — данных в базе нет.

| Тема | Статус | Где искать | Куда переносить |
|---|---|---|---|
| Название, год основания, офисы | есть | справка партнёра, страница «О компании» | `about/company.md`, `profile.json` |
| История и Entensys | частично | страница «О компании», пресс-релизы юбилеев | `about/history.md` |
| Экосистема SUMMA и UGOS | есть | `usergate.com/products`, документация | `about/ecosystem-summa.md` |
| Назначение продуктов | есть | справка партнёра, страницы продуктов | `products/*.md` |
| Функции по продуктам | частично | руководства администратора по версиям | `products/*.md` |
| Версии продуктов | есть | `docs.usergate.com/dokumentaciya-k-versiyam-po-v-pdf_769.html` | `docs/versions-and-platforms.md` |
| Аппаратные платформы и модели | частично | раздел «Аппаратные платформы», datasheet'ы | `docs/versions-and-platforms.md` |

## Как пользоваться

1. Выберите тему со статусом **нет** или **частично**.
2. Откройте соответствующий CSV в `01-web` … `08-contacts` и найдите канал.
3. Соберите факты, оформите по шаблону, перенесите в `data/company/`.
4. Обновите статус в этой таблице — она должна отражать реальное состояние базы.
