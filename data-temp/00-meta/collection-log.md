# Журнал сбора данных

Короткие записи «что сделано, когда и кем». Нужен, чтобы через месяц было понятно, откуда взялся файл и почему источник отклонён.

Формат записи:

```
## ГГГГ-ММ-ДД — что сделано
- канал: сайт / документация / telegram / реестр / пресса
- источники: URL или файл
- результат: перенесено в … / отклонено, потому что …
- кто: инициалы
```
