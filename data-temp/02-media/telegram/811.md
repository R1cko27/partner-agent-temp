💀 Уязвимость высокого уровня опасности, связанная с переполнением динамической памяти в Oracle Java SE и Graal VM: CVE-2026-114938
➡️ Описание
Уязвимость CVE-2026-114938 (неофициальное название — Java4Shell) обнаружена в продуктах Oracle Java SE, Oracle GraalVM for JDK и Oracle GraalVM Enterprise Edition; затронут компонент Compiler. Причина возникновения — переполнение динамической памяти (heap-based buffer overflow, CWE-122).
Для эксплуатации уязвимости не требуется прохождение аутентификации и взаимодействие с пользователем; доступ осуществляется по сети через несколько протоколов. Сложность атаки оценивается как высокая. Эксплуатация возможна через передачу данных в API компонента Compiler, например через веб-сервис. Использование небезопасных Java Web Start и апплетов при этом не требуется.
Последствия успешной эксплуатации — полный перехват системы: потеря конфиденциальности, целостности и доступности ресурсов.
➡️ Рейтинг
Уязвимость получила оценку 8,1 по CVSS 3.1.
➡️ Уязвимые версии и продукты
🔸Oracle Java SE: версии 8u511b33-perf, 17.0.21.0.3, 21.0.13.0.3, 25.0.5.0.3, 27.0.1.0.3;
🔸Oracle GraalVM for JDK: версии 17.0.21.0.3, 21.0.13.0.3;
🔸Oracle GraalVM Enterprise Edition: версия 21.3.20.0.3.
➡️ Рекомендации
Специалисты центра мониторинга и реагирования UserGate рекомендуют пользователям выполнить следующие действия:
🔸обновить Oracle Java SE до одной из версий: [17.0.21.1](http://17.0.21.1/), [21.0.13.1](http://21.0.13.1/), [25.0.5.1](http://25.0.5.1/), [27.0.1.1](http://27.0.1.1/);
🔸обновить GraalVM for JDK до одной из версий: [17.0.21.1](http://17.0.21.1/), [21.0.13.1](http://21.0.13.1/), [25.0.5.1](http://25.0.5.1/);
🔸обновить Oracle GraalVM Enterprise Edition до версии [21.3.20.1](http://21.3.20.1/);
🔸проверить актуальность подписки на модуль Security Updates для uNGFW и OWASP Top 10 для uWAF;
🔸в uNGFW включить в блокирующем режиме IDPS-сигнатуру Possible Java Base64 decoder memory corruption;
🔸в uWAF включить в блокирующем режиме правило Possible Java Base64 decoder memory corruption.
