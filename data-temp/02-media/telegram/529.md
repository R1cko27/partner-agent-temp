Дата: 2025-12-05 · Пост: 529 · Просмотры: 1450

💀 Критическая уязвимость неаутентифицированного удаленного выполнения кода в React Server Components
CVE-2025-55182 позволяет неаутентифицированному пользователю выполнять произвольный код на уязвимом сервере. Для этого достаточно отправить предварительно сформированный HTTP-запрос на сервис с React Server Components. Опасность оценена в 10 баллов по шкале CVSS 3.1.
В случае успешной эксплуатации злоумышленник может получить разные возможности — от чтения произвольных файлов до выполнения команд ОС.
Причиной уязвимости стали небезопасная десериализация ввода к конечным точкам серверных функций в React Server Components и использование функций, связанных с выполнением команд ОС.
Кому угрожает эта проблема и как от нее защититься уже рассказали на сайте.
