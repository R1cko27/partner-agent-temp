# UserGate и системный интегратор Angara Security обеспечили двойной контур информационной…

Дата: 2023-07-20 · Пост: 116 · Просмотры: 1120

UserGate и системный интегратор Angara Security обеспечили двойной контур информационной безопасности для российской компании, создающей технологии искусственного интеллекта в медицинской отрасли.
Специалисты Angara Security провели аудит инфраструктуры заказчика. По итогам анализа российских разработок в сфере сетевой безопасности был выбран комплекс решений от UserGate, включающий в себя поставку и настройку аппаратных платформ UserGate D500 с возможностью фильтровать трафик по пользователям и поддержкой eBGP.
