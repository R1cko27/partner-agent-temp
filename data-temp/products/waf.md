## Версии в документации

По перечню «Документация к версиям ПО в PDF» ([статья 769](https://docs.usergate.com/dokumentaciya-k-versiyam-po-v-pdf_769.html), обновлена 23.10.2026) для WAF опубликованы:

| Версия | Руководство | Файл |

| 7.6.x | Руководство администратора (RU) | https://docs.usergate.com/pdf_manuals/waf/waf-7.6.x-manual.pdf |
| 7.7.x | Руководство администратора (RU) | https://docs.usergate.com/pdf_manuals/waf/waf-7.7.x-manual.pdf |
| 7.7.0 | Руководство по API (EN) | https://docs.usergate.com/pdf_manuals/waf/api-docs-waf-7.7.0.pdf |

Релиз-ноты продукта в карте портала: только 7.6.0 — `usergate-waf-760(build-760491986r-09062026)` и `usergate-waf-760(build-760466365r-18052026)`.

### Версия 7.5.0 — НЕ подтверждена

В перечне PDF-руководств WAF версии 7.5.0 нет. В карте портала ([sitemap.xml](https://docs.usergate.com/sitemap.xml)) релиз-нот WAF 7.5.0 также нет — единственные релиз-ноты WAF относятся к 7.6.0.

**Вывод:** «анонс 7.5.0» в указанных источниках не найден. Называть 7.5.0 опубликованной версией WAF нельзя, пока она не появится в документации или в перечне руководств.

Отдельная страница про 7.5.0 в документации есть только у кластеров NGFW — «Настройка кластеров (версия 7.50 и выше)», но это NGFW, а не WAF.
