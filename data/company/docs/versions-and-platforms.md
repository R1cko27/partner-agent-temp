## Операционная система UGOS

- Ядро экосистемы SUMMA, проприетарная ОС UserGate.
- В документации DCFW 8.x прямо указана «операционная система UGOS 8.0 для DCFW».
- Соответствие «версия продукта → версия UGOS» для каждого продукта проверяется по его руководству администратора, а не выводится по аналогии.

## Аппаратные платформы

- Продукты поставляются как программно-аппаратные комплексы собственной разработки; компания выпускает собственные платформы и микросхемы ASIC.
- В материалах упомянуты платформы «Катунь Электроника»; в документации фигурируют модели, например B50, C150, а также C100, D200, D500, E1000, E3000, F8000 и другие.
- Для каждого продукта публикуется матрица совместимости версий ПО с аппаратными платформами. Пример раздела: «Совместимость с аппаратными платформами» в дереве документации продукта.
- Для Management Center отдельно публикуется совместимость версий MC с версиями продуктов UserGate.
