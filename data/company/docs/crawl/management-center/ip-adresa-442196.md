# IP-адреса

Списки IP-адресов используются при создании правил для устройств, подключенных к UserGate MC. Например, в правиле межсетевого экрана в качестве адресов источника трафика можно добавить списки IP-адресов из общей библиотеки.
Вы можете создавать статические списки IP-адресов, которые хранятся в UserGate MC, и обновляемые, которые автоматически пополняются из файлов, размещенных на внешнем сервере.
Примечание
Подробнее о добавлении обновляемых списков элементов — в разделе «
Настройка обновляемых списков элементов

5. В блоке
Элементы списка
нажмите
Добавить ➜
Добавить элемент
6. В открывшемся окне укажите IP-адрес.
Примечание
В поле допускается вводить IP-адрес (например, 192.0.2.25), диапазоны IP-адресов (например, 192.0.2.1
192.0.2.25), а также адреса подсетей в формате CIDR (например, 192.0.2.0/24).

8. Для добавления других IP-адресов в список повторите шаги 5–7 инструкции.
