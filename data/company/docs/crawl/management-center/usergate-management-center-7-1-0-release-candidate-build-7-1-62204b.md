# UserGate Management Center 7.1.0 Release Candidate (build 7.1.0.1605RC, 16/11/2023)

Содержание:
Release Notes:
Статус
Release Candidat
Новые возможности
№ задачи
Описание
UGDNS-3576
Добавлен собственный VPN-клиент для конечных устройств UserGate Client с поддержкой протоколов IKEv1 и IKEv2.
UGDNS-4647
Добавлена возможность создания гибких политик безопасности с помощью правил МЭ, позволяющх фильтровать информационные потоки на основе пользователя, адресов источника/назначения, сервисов, приложений, списков и категорий URL, типа контента, комплаенса.
UGDNS-11855
Добавлена поддержка централизованного управления конечными устройствами с установленным ПО UserGate Client из консоли Management Center.
UGDNS-13347
Добавлен таймер автоматического закрытия сессии администратора.
UGDNS-14944
Добавлена проверка соответствия конечного устройства заданным условиям (комплаенс), реализованная с помощью профилей HIP (Host Information Profile).
UGDNS-14987
Добавлена возможность выбора необходимых алгоритмов эллиптических кривых в профилях SSL-инспектирования.
UGDNS-15397
Добавлена тёмная тема интерфейса.
UGDNS-16687
Добавлено поле Алиас в свойствах интерефйса для работы с SNMP.
UGDNS-17216
Добавлена возможность мониторинга доступа к серверам DNS через API.
UGDNS-17881
Добавлена поддержка алгоритмов хеширования семейства SHA-2 для аутентификации SNMP-менеджера.
UGDNS-18093
Добавлена возможность добавления разделов в избранное и отображение в веб-интерфейсе только этих разделов. В шаблонах управляемых устройств доступно отображение только модулей, в которые были внесены изменения.
UGDNS-18775
Расширен функционал CLI и PMC CLI.
UGDNS-19600
Оптимизирован процесс синхронизации конфигурации между MC и кластером NGFW.
