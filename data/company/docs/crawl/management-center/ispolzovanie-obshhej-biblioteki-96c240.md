# Использование общей библиотеки

Содержание:
При настройке правил в шаблонах конфигурации управляемого устройства следует учитывать особенности работы с общими библиотеками. В этом разделе описаны действия, для которых в качестве примера выбрана настройка правила межсетевого экрана устройства UserGate NGFW. Действия при настройке других объектов конфигурации, где можно использовать списки элементов из общей библиотеки, аналогичны описанным.
Добавление существующего списка элементов из общей библиотеки в правило
Чтобы добавить существующий список элементов из общей библиотеки в правило межсетевого экрана:
1. В управляемой области на странице
NGFW
в разделе
Политики сети ➜ Межсетевой экран
откройте окно свойств нового или существующего правила.
2. Перейдите на вкладку с параметрами, для настройки которых можно использовать списки элементов из библиотеки, например на вкладку
Источник
3. В секции
Адрес источника
нажмите добавить и выберите
Добавить список IP-адресов
(или
Добавить список доменов
4. В окне выбора списков IP-адресов перейдите на нужную вкладку и добавьте списки элементов из общей библиотеки, библиотек шаблонов или из предустановленных списков.
Примечание
Вы можете добавлять элементы из одной или из всех библиотек.
5. Закройте окно и  продолжите настройку других параметров правила.
Создание списка элементов для общей библиотеки при настройке правила
При создании правила в шаблоне конфигурации вы можете добавить новый список в окне настройки правила, если существующие списки не подходят. Новый список можно сохранить либо в общую библиотеку, либо в библиотеку шаблонов. Выбор библиотеки зависит от ваших целей: используйте общую библиотеку, если планируете применять этот список в конфигурациях устройств разных типов, а также если вам важны история изменений элемента и отслеживание его зависимостей.
Чтобы создать и добавить новый список элементов в окне настройки правила:
1. В управляемой области на странице
NGFW
в разделе
Политики сети ➜ Межсетевой экран
откройте окно свойств нового или существующего правила.
2. Перейдите на вкладку с параметрами, для настройки которых можно использовать списки элементов из библиотеки, например, на вкладку
Источник
3. В открывшемся окне в секции
Адрес источника
нажмите
Создать и добавить новый объект
и выберите один из пунктов в меню, например
Добавить список IP-адресов
4. На вкладке
Общие
укажите название и при необходимости описание списка элементов, а также выберите уровень угрозы.
5. В секции
IP-адреса
выберите, в какую библиотеку будет добавлен новый список элементов: в общую (
Сохранить в общей библиотеке
) или в библиотеку конкретного шаблона (
Сохранить в шаблоне
6. В секции
IP-адреса
нажмите
Добавить
и выберите
Добавить список
Примечание
Вы также можете добавлять отдельные элементы, выбрав в этом меню «Добавить элемент».
7. В окне выбора списка добавьте нужные списки элементов и при необходимости предустановленные списки, после чего закройте окно.
Важно!
В списки общей библиотеки можно добавлять только объекты из общей библиотеки, а в списки библиотек шаблонов — только объекты из библиотек шаблонов.
8. Нажмите
и продолжите настройку остальных параметров правила.
Созданный список элементов будет сохранен в выбранной библиотеке.
