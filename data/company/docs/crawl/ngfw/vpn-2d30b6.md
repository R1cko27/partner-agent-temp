# VPN

Documentation:
Раздел
VPN
отображает всех пользователей и все серверы, подключенные по VPN к данному серверу. Для каждого соединения отображается следующая информация:
Пользователь
— имя пользователя, под которым произошла аутентификация соединения.
Роль этого сервера
— клиент или сервер.
Время сессии
— продолжительность установленного соединения.
Туннельный IP
— адрес, назначенный данному клиенту в виртуальной частной сети.
IP-адрес
— адрес, с которого инициировано соединение VPN.
Geo IP
— страна по Geo IP, откуда установлено соединение.
Шифрование
— тип шифрования
v6.x
v7.x
