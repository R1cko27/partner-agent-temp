# Запретить NAT "серых" IP адресов

Technology: Firewall
Задача
Необходимо запретить NAT трансляцию серых адресов.
Решение
Для решения задачи необходимо выполнить следующие шаги:
1. Добавить список запрещенных для NAT IP-адресов. Для этого по пути:
Библиотеки ➜ IP-адеса
, нужно добавить список запрещенных для NAT адресов.
2. В правилах NAT добавить данный список в качестве
Источника
или
Назначения
с установкой флага
Инвертировать
. Для этого: по пути:
Политики сети
NAT
и маршрутизация, добавить правило NAT или отредактировать существующее. Открыть настройки
Источника
и/или
Назначения
, и добавить запрещенные адреса с флагом
Инвертировать.
