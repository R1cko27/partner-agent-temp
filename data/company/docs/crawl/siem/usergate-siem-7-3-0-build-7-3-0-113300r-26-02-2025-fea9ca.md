# UserGate SIEM 7.3.0(build 7.3.0.113300R, 26/02/2025)

Содержание:
Release Notes:
Статус
Отозвано
Внимание!
Версия в стадии бета-тестирования и не рекомендуется для массовой установки в производственную инфраструктуру (production). Задача этой сборки: проверка в "боевых условиях" у лояльных клиентов, сбор обратной связи и выявление потенциальных недостатков на ранней стадии.
Новые возможности
№ задачи
Описание
SUM-7555
Выпущен SIEM в виде отдельного продукта. Logan и SIEM технически разведены для самостоятельного развития в рамках экосистемы SUMMA.
SUM-4859
Добавлена возможность создания кластера отказоустойчивости для SIEM (актив-пассив). Добавлен новый тип узла кластера Арбитратор, обеспечивающий консистентность данных.
SUM-12938
Добавлена библиотека экспертизы правил нормализации для различных источников событий от MRC UserGate, позволяющая оперативно и корректно подключить источники событий в инфраструктуре заказчика. Библиотека нормализации доступна в базовой лицензии продукта.

Критические изменения в версии
Важно!
Введена новая система лицензирования.
Теперь SIEM лицензируется по ядрам (эквивалент 1cpu = 1000 Event Per Second). Без лицензии подключение источников недоступно, с активированной лицензией ограничение снимается.
Обновление с предыдущих версий
Важно!
Cтарые инсталляции SIEM 7.1.х 7.2.х нельзя обновлять до нового SIEM 7.3.х , необходима новая инсталляция.
