# Профили редистрибуции

Documentation:
Описание
Предназначены для определения круга устройств UserGate, на которые отправляется информация о найденных агентом UserID пользователях. Для добавления профиля необходимо нажать кнопку
Добавить
и настроить профиль.
Наименование
Описание
Название
Название профиля.
Описание
Описание профиля (опционально).
Сенсоры UserGate
Список устройств UserGate, на которые будет отправлена информация о найденных пользователях.
Добавление сенсоров доступно разделе
Сенсоры ➜ Сенсоры UserGate
рабочего стола
Настройки
Примечание
По умолчанию создан профиль
Share with all UserGate sensors
, при выборе которого информация о пользователях будет отправлена на все сенсоры SIEM.
