# Правила поступления

1. Оставьте заявку на сайте или напишите в приёмную комиссию.
2. Пройдите короткое интервью: цель обучения, опыт, удобный формат.
3. Для DevOps пройдите вступительный тест по Linux и сетям.
4. Выберите программу и формат, получите договор и график оплаты.
5. Внесите оплату или оформите рассрочку.
6. Получите доступ к платформе и расписание.

Для взрослых программ нужен паспорт. Для школьников — паспорт родителя и свидетельство о рождении. Для корпоративных групп — договор и список участников.

Перенос старта возможен один раз без потери оплаты при предупреждении за 3 дня. Возврат — по политике возврата.
