💀 Критически опасная уязвимость удаленного выполнения команд во FreeSWITCH: CVE-2026-116779
➡️ Описание
Уязвимость SIP2Shell (CVE-2026-116779) обнаружена во FreeSWITCH от SignalWire. Она возникает в функции sofia_presence_handle_sip_i_message(), которая при обработке входящего SIP-сообщения MESSAGE интерпретирует часть значения заголовка «To» до символа «+» как селектор протокола чата. При указании протокола «api» происходит вызов switch_api_execute(), что позволяет выполнить с привилегиями демона команды API FreeSWITCH, включая команды операционной системы. Для эксплуатации уязвимости не требуются аутентификация и взаимодействие с пользователем.
➡️ Рейтинг
Уязвимость получила оценку 9,8 по CVSS 3.1.
➡️ Уязвимые версии и продукты
FreeSwitch (SignalWire) версий ниже 1.11.3.
➡️ Рекомендации
Специалисты центра мониторинга и реагирования UserGate рекомендуют пользователям выполнить следующие действия:
🔸обновить FreeSwitch до версии 1.11.3;
🔸проверить актуальность подписки на модуль Security Updates для uNGFW;
🔸в uNGFW включить в блокирующем режиме IDPS-сигнатуру FreeSWITCH SIP MESSAGE API Command Execution.
За дополнительной информацией обращайтесь к нашим специалистам: ufactor@usergate.com.
