# ⚡ Центр мониторинга и реагирования UserGate предупреждает о критической уязвимости…

Дата: 2023-08-04 · Пост: 124 · Просмотры: 1190

⚡ Центр мониторинга и реагирования UserGate предупреждает о критической уязвимости удаленного выполнения кода (RCE) в плагине File Manager Advanced Shortcode для WordPress (CVE-2023-2068).
CVE-2023-2068 – уязвимость, которая не позволяет должным образом предотвратить загрузку файлов с запрещенными MIME-типами при использовании шорткодов в плагине File Manager Advanced.
