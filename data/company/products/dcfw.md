# UserGate DCFW

Межсетевой экран для центров обработки данных (Data Center Firewall). Решение, специально ориентированное на защиту ЦОД и высоконагруженных инфраструктур.

## Назначение

Защита центров обработки данных и высоконагруженных инфраструктур. Отличается от NGFW акцентом на сценарии дата-центра: пропускная способность, отказоустойчивость, кластеризация, маршрутизация и централизованное управление парком устройств.

## Функциональные возможности (версия 8.x, ОС UGOS 8.0)

По руководству администратора DCFW 8.x:

Сеть и маршрутизация:

- статическая и динамическая маршрутизация;
- поддержка VLAN;
- технологии балансировки нагрузки и управления качеством обслуживания (QoS);
- фильтрация на уровнях L3–L7;
- различные типы трансляции адресов (NAT);
- поддержка VPN-туннелей.

Аутентификация и идентификация пользователей:

- механизмы Captive-портал и NTLM;
- учётные записи из LDAP, Active Directory, FreeIPA, TACACS+, RADIUS, SAML IDP;
- прозрачная авторизация пользователей домена Active Directory без запроса логина и пароля;
- в Captive-портале возможна аутентификация по сертификатам на базе PKI;
- функциональность UserID — прозрачная аутентификация по журналам Active Directory, syslog и сообщениям RADIUS accounting.

Безопасность:

- идентификация приложений;
- система обнаружения вторжений (СОВ): обнаружение, протоколирование и предотвращение угроз в реальном времени, отчёты;
- собственные сигнатуры администратора для защиты отдельных сервисов, включая их в профили наряду с поставляемыми UserGate; профили интегрируются в правила межсетевого экрана.

Отказоустойчивость:

- кластер конфигурации — единые настройки узлов в рамках кластера;
- кластер отказоустойчивости в режимах «активный-активный» и «активный-пассивный»;
- оба режима поддерживают синхронизацию пользовательских сессий — переключение трафика прозрачно для пользователей.

Эксплуатация:

- мониторинг по SNMP v2c и SNMP v3, запросы и оповещения (traps);
- профили оповещений по SMTP (email) и SMPP (SMS);
- централизованное управление через UserGate Management Center: мониторинг управляемых устройств, применение настроек, политики для групп устройств;
- журналы событий, сетевого трафика, веб-доступа, DNS-запросов, работы СОВ, агента UserID и истории поиска;
- автоматический экспорт событий на внешние серверы (SSH, FTP, syslog);
- отчёты по встроенным и пользовательским шаблонам;
- хранение и обработка журналов и отчёты могут выполняться на внешнем сервере UserGate Log Analyzer.

## Кластеры и отказоустойчивость

UserGate DCFW поддерживает **два типа кластеров**: кластер конфигурации, который задаёт единые настройки узлам в рамках кластера, и кластер отказоустойчивости, который обеспечивает резервирование. Кластер отказоустойчивости объединяет до **четырёх узлов** кластера конфигурации и работает в режиме «активный-активный» или «активный-пассивный»; таких кластеров можно собрать несколько.

Служебный трафик кластера передаётся по multicast или unicast, узлы идентифицируются по VRID. Для служебных пакетов VRRP в кластере отказоустойчивости поддерживается **подпись IPsec Authentication Header**: параметр `auth-type` включает подпись служебных пакетов.

Часть параметров остаётся уникальной для каждого узла и не реплицируется: Log Analyzer, диагностика, интерфейсы, шлюзы, DHCP, маршруты, OSPF и BGP.

Мониторинг поддерживается по SNMP v2c и SNMP v3 — как запросы (queries), так и оповещения (traps).

Источники: https://docs.usergate.com/klasterizaciya-i-otkazoustojchivost6_1605.html, https://docs.usergate.com/funkcional6nye-vozmozhnosti_2248.html

## Выход узла из кластера

При выходе узла из кластера конфигурации общие настройки кластера на нём больше не действуют: узел возвращается к собственным параметрам. Уникальными для каждого узла остаются Log Analyzer, диагностика, интерфейсы, шлюзы, DHCP, маршруты, OSPF и BGP — они не реплицируются и настраиваются отдельно.

Обратный сценарий в документации описан подробно: при подключении нового узла все параметры первого узла реплицируются на него, после чего узел получает общие настройки кластера. Поэтому перед выводом узла проверяют, какие параметры были заданы только на нём.

Источники: https://docs.usergate.com/klasterizaciya-i-otkazoustojchivost6_1605.html

## Лицензирование кластера

Модуль Cluster обеспечивает работу UserGate DCFW в режиме кластера. При приобретении нескольких устройств DCFW для работы в кластере дополнительно **бесплатно предоставляется лицензия на количество узлов**, входящих в кластер. Срок действия такой лицензии не ограничен.

Источник: https://docs.usergate.com/ (руководство администратора DCFW, раздел лицензирования)

## UserID: способы аутентификации

UserID — прозрачная аутентификация по журналам. Она не заменяет, а дополняет другие способы: **Captive-портал, NTLM, LDAP, Active Directory, RADIUS, SAML IDP**. В разделе «Пользователи и устройства» для каждого способа настраивается свой профиль, а UserID связывает сетевой адрес с именем пользователя.
