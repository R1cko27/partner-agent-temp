# База знаний по компании UserGate

Здесь лежат все материалы о компании, которые видит ассистент. Код читает эту папку при сборке индекса (`python ingest.py`); ничего кроме данных менять не нужно. Сам README в индекс не попадает.

Компания: **UserGate** (ООО «Юзергейт»), российский разработчик решений в сфере информационной безопасности.

## Как устроена папка

```
data/company/
├── profile.json          карточка компании: факты, контакты, продукты
├── agent.json            профиль ассистента: роль, правила, глоссарий, брендинг
├── urls.txt              официальные страницы, которые скачиваются при сборке
├── README.md             этот файл (в индекс не попадает)
├── about/                о компании, история, экосистема, партнёры, контакты, карьера
├── products/             карточки продуктов: назначение, функции, версии, ограничения
├── faq/                  частые вопросы в формате «Q: … / A: …»
├── news/                 новости: курируемые + Telegram (621) и VK (10)
└── docs/                 справочные документы + crawl/: собранные страницы
    ├── academy-courses.md         курсы и экзамены Академии с ценами
    ├── cluster.md                 кластеры NGFW: параметры, VRRP, платформы
    ├── versions-and-platforms.md  версии продуктов и совместимость
    ├── site-facts-2026-11-22.md   факты с портала документации (IPMI, WAF, SWG, SNMP, Captive, UserID, DCFW 8)
    ├── source-registry.md         происхождение каждого факта
    ├── limitations-and-unknowns.md чего в базе нет
    └── crawl/                     документация и сайт: 2756 файлов
        ├── ngfw/                  ~820 страниц руководства администратора NGFW
        ├── waf/ swg/ dcfw/        документация по продуктам
        ├── _general/              аппаратные платформы, глоссарий, портал документации
        └── habr/                  153 статьи
```

Объём: около **3465 файлов** материалов, ~**36,6 тыс. фрагментов** после нарезки.
Собранные страницы лежат в `docs/crawl/<продукт>/` и `docs/crawl/habr/`, посты
соцсетей — в `news/telegram/` и `news/vk/`.

Тип материала определяется папкой: `about/` → о компании, `products/` → продукт, `faq/` → частые вопросы, `news/` → новость, `docs/` → документ. Внутри папок можно создавать подпапки — тип наследуется.

## Правила, которых держится база

Эти правила заданы описанием кейса и нарушать их нельзя — на них построены проверочные сценарии.

1. **Не обобщать.** «Все продукты сертифицированы» из примера одного продукта не выводится. В базе сертификат указан только для NGFW.
2. **Не переносить между продуктами и версиями.** Функция, характеристика, сертификат и совместимость относятся к конкретному продукту и конкретной версии.
3. **Не выдумывать цены и сроки.** В `faq/pricing.md` зафиксирован правильный ответ: данных нет и вот официальный канал.
4. **Не протаскивать мусор поисковой выдачи.** Обрывки вида `krayon.ru +1` удалены из справки партнёра и в индекс не попадают (см. `docs/source-registry.md`, раздел 4).
5. **Справка партнёра — это исходный материал, а не истина в последней инстанции.** Даты, численность сотрудников и география помечены как сведения справки и проверяются на официальном сайте.
6. **У каждого утверждения есть источник.** В конце каждого файла — блок «Источники» с URL и датой обращения.

## Форматы и как добавить материал

Поддерживаются `.md`, `.txt`, `.html`, `.pdf`, `.docx`, `.json`, `.csv`. Проще всего — Markdown: он читается человеком и хорошо режется на фрагменты.

**Новый продукт.** Создать `products/имя-продукта.md`, первая строка — `# UserGate Название`. Дальше разделы: «Назначение», «Ключевые функции», «Версии и документация», «Ограничения», «Источники». Заголовок первого уровня становится названием карточки продукта.

**Новый вопрос.** Добавить в подходящий файл `faq/*.md` пару строк:

```
Q: Вопрос как его задаёт пользователь?
A: Ответ по существу, со ссылкой на источник.
```

Пустая строка между парами обязательна. Ответ длиннее 900 символов обрезается — лучше держать в пределах 600.

**Новая новость.** Файл `news/ГГГГ-ММ-ДД-короткое-имя.md`, первая строка — заголовок. Дату в тексте писать как `2026-11-20`; если известен только месяц, писать «апрель 2026 (точный день не указан)» — но не придумывать число.

**Новая страница документации.** Добавить URL в `urls.txt` в раздел по теме и пересобрать базу.

**Факты с портала документации.** Скачать статью и свести выжимку в `docs/site-facts-*.md`:

```bash
python tools/crawl_site.py --url https://docs.usergate.com/<статья>.html --limit 1
```

Краулер складывает страницу в `data-temp/09-company/docs/<продукт>/`. Из неё в
`docs/site-facts-<дата>.md` переносится только проверяемая выжимка с ссылкой на источник.

## Как обновлять

```bash
python ingest.py               # полная сборка: BM25 + эмбеддинги + загрузка URL
python ingest.py --no-web      # без скачивания URL (быстро, офлайн)
python tests/test_partner.py   # проверка домена и API
```

**Быстрое пополнение без полной пересборки.** Один документ можно добавить в
инкрементальный слой `storage/index/delta/`; поиск подхватит его сразу:

```bash
python tools/add_docs.py --file data/company/docs/файл.md --as docs/файл.md
```

Фрагменты лягут в `storage/index/delta/chunks.jsonl`, манифест обновится. Полная
пересборка векторов (`ingest.py`) всё равно нужна для Chroma.

После изменения данных кэш ответов инвалидируется автоматически: отпечаток материалов входит в ключ кэша.

## Ограничения базы

- Автоматически не загружаются `usergate.com/products`, `/academy/courses-exams` и `/registry-entry`: сайт отдаёт страницы как SPA и закрыт капчей. Это канонические адреса для проверки человеком, а не источники для индекса.
- Статьи `docs.usergate.com` загружаются статически через `tools/crawl_site.py`; часть разделов (например, журналы DCFW 8.x) ещё не обойдена.
- Технические характеристики по моделям оборудования в базу не переносились: они меняются от платформы к платформе и проверяются в документации.
- Персональных данных сотрудников и внутренних документов в базе нет.

## Куда складывать новое, пока его нет

Для сбора материалов «снаружи» — сайт, соцсети, реестры, пресса, вакансии — заведена отдельная папка `data-temp/`. Она не попадает в индекс и служит рабочим столом: собрали, проверили, оформили — перенесли сюда.
