# Открытые источники, которые загружаются при сборке базы знаний.
#
# Формат: один URL на строку. Строки, начинающиеся с «#», игнорируются.
# Эти страницы скачиваются при `python ingest.py` и попадают в индекс
# как источник с типом «web»; в ответах ссылка ведёт на точный URL страницы.
#
# Правила для этого файла:
#   1. Только официальные страницы компании (домен usergate.com или docs.usergate.com).
#   2. Только конкретная статья/раздел, а не главная страница.
#   3. Не добавлять страницы без текста: оболочки SPA и заглушки бесполезны в индексе.
#   4. После изменения — пересобрать базу: `python ingest.py`.
#
# ВАЖНО: usergate.com отдаёт страницы как SPA (текст собирается в браузере)
# и закрыт Yandex SmartCaptcha, поэтому /products, /academy/courses-exams и
# /registry-entry автоматически не загружаются — они остаются каноническими
# адресами для проверки человеком. Портал документации docs.usergate.com
# отдаёт содержимое сервером, поэтому именно он используется как источник.
#
