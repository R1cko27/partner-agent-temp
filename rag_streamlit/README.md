# RAG-прототип на Streamlit

Локальный инструмент: берёт PDF и TXT из папки, страницы по ссылкам, режет на чанки,
считает эмбеддинги, кладёт в ChromaDB и отвечает на вопросы с указанием источников.

Ключевое свойство: **загрузка только добавляет данные.** База не пересоздаётся,
старые документы не стираются, повторная индексация того же файла не даёт дублей.

## Быстрый старт

```bash
cd rag_streamlit
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt

copy .env.example .env          # и впишите OPENROUTER_API_KEY
streamlit run app.py
```

Откроется `http://localhost:8501`.

Без ключа OpenRouter интерфейс тоже запускается: поиск и найденные фрагменты работают,
а на вопрос про ответ модель сообщит, что недоступна. Для полностью локального режима
переключите провайдер на «Локальная (Ollama)» — по умолчанию ждёт
`http://127.0.0.1:11434/v1` с моделью `qwen2.5:3b-instruct`.

## Что внутри

```
rag_streamlit/
├── app.py            интерфейс: поиск, индексирование, состояние базы
├── core.py           загрузка PDF/TXT/URL, чанкинг, эмбеддинги, ChromaDB
├── llm.py            OpenRouter или локальная модель, промпт «только по контексту»
├── requirements.txt
├── .env.example
├── data/             сюда кладите PDF и TXT (создаётся при первом запуске)
└── storage/          chroma.sqlite3, manifest.json, кэш моделей
```

## Как устроена аддитивность

Три механизма, из-за которых данные не теряются:

1. **Коллекция не пересоздаётся.** Нет ни `reset()`, ни удаления коллекции: при старте
   вызывается `get_or_create_collection`.
2. **Идентификаторы чанков детерминированы:** `sha1(doc_id + индекс + текст)`. Запись идёт
   через `upsert`, поэтому повторная индексация того же файла обновляет те же записи,
   а не плодит копии.
3. **Манифест `storage/manifest.json`** помнит `doc_id`, хеш текста и число чанков.
   Если хеш не изменился, документ пропускается целиком — видно в отчёте как «пропущено».

Удаление есть только как отдельное явное действие на вкладке «База»: кнопка «Удалить
документ» с подтверждением. Кнопка «Удалить всю базу» намеренно отключена.

## Параметры

| Что | Значение | Где менять |
|---|---|---|
| Размер чанка | 800 символов | `core.py`, `CHUNK_SIZE` |
| Перекрытие | 150 символов | `core.py`, `CHUNK_OVERLAP` |
| Модель эмбеддингов | `paraphrase-multilingual-MiniLM-L12-v2` (384) | `core.py`, `EMBED_MODEL` |
| Сколько фрагментов в контекст | 3 (ползунок 1–10) | боковая панель |
| Провайдер и модель | OpenRouter или Ollama | боковая панель |

Модель эмбеддингов мультиязычная, поэтому русские вопросы и русские документы
ложатся в одно пространство. Скачивается один раз в `storage/models`.

## Честность ответа

- Если поиск не нашёл ни одного фрагмента, модель **не вызывается** — сразу отдаётся
  «В базе нет информации».
- В системном промпте три ограничения: отвечать только по контексту, не додумывать числа
  и названия, при отсутствии данных сказать ровно «В базе нет информации».
- Если ответ пустой, он тоже трактуется как отсутствие данных.
- Источники показываются двумя способами: списком (файл или URL) и, по желанию,
  найденными фрагментами с оценкой схожести — чтобы ответ можно было проверить.

## Что загружается по ссылке

Страница скачивается через HTTP, из HTML вырезаются `script`, `style`, `noscript`,
`nav`, `footer`, `header`, `aside`, `form`, остальное превращается в текст.
Заголовок берётся из `<title>`. Источником документа становится сам URL.

Ограничения, о которых честно стоит помнить:

- страницы, которые рисуют контент JavaScript-ом, могут дать пустой текст — интерфейс об этом предупредит;
- сканы PDF без текстового слоя не распознаются (нужен OCR, его здесь нет);
- капчи и авторизация не обходятся: если сайт закрыт, загрузка честно завершится ошибкой.

## Проверка работоспособности

Быстрый сценарий:

1. Положите 2–3 файла в `data/` (PDF или TXT).
2. Вкладка «Индексирование» → «Проиндексировать папку» → в отчёте должно быть `добавлено документов: N`.
3. Нажмите ту же кнопку ещё раз → `пропущено как уже загруженные: N`, а число фрагментов не вырастет.
4. Добавьте ссылку → появится новый документ, старые останутся на месте.
5. Задайте вопрос по загруженному тексту → ответ со списком источников.
6. Задайте вопрос не по теме → «В базе нет информации».
