Обновление программного обеспечения — это критически важная процедура, напрямую влияющая на безопасность, стабильность и доступность сети. Своевременная установка обновлений необходима для защиты от новых уязвимостей и получения доступа к актуальным функциям безопасности. Одним из ключевых аспектов этого процесса является соблюдение рекомендованного пути обновления.

Путь обновления — это последовательность версий ПО, через которые необходимо пройти при переходе от текущей версии системы к целевой. В некоторых случаях обновление нельзя выполнить за один шаг, потребуется последовательная установка промежуточных версий с использованием конвертера конфигураций.

Рекомендованный путь обновления протестирован и гарантирует корректную миграцию конфигурации и внутренних компонентов системы при соблюдении процедуры обновления.

Прямое обновление программного обеспечения до целевой версии рекомендуется выполнять с совместимых версий. Обновление с остальных версий возможно только после предварительного обновления до указанных совместимых версий в соответствии с данной таблицей.

Варианты обновления программного обеспечения

Обновление программного обеспечения UserGate NGFW может быть выполнено следующими способами:

  • Прямое обновление штатными средствами продукта. Обновление возможно для версий, указанных в таблице совместимости. Подробнее — в разделе «Обновление ПО UserGate».

  • Чистая установка с импортом конфигурации. Если устройство не используется в продуктивной среде, возможна чистая установка целевой версии программного обеспечения с переносом конфигурации с помощью конвертера конфигурации.

    Подробнее о конвертере — в разделе «Конвертер конфигураций UserGate».

    Подробнее о чистой установке ПО UserGate на аппаратных платформах:

    • «Установка ПО UserGate на аппаратных платформах C100, D200, D500, E1000, E3000, F8000»;

    • «Установка ПО UserGate на аппаратных платформа E1010, E3010, F8010»;

    • «Обновление компонентов ПО с использованием PMC на аппаратных платформах B50, C150, C151, D250, FG».

Общие рекомендации по обновлению программного обеспечения

Чтобы минимизировать риски при обновлениях, рекомендуется:

  • Проверить текущую и целевую версии ПО устройства.

  • Ознакомиться с информацией о версиях в разделе «Описание версий».

  • Сделать резервную копию конфигурации устройства, чтобы в случае возникновения проблем во время обновления можно было восстановить его предыдущее состояние.

  • Во время установки обновления создать точку восстановления системы. Это позволит оперативно вернуть систему в рабочее состояние.

В случае возникновения аварийной ситуации при обновлении обратитесь в службу технической поддержки.

Обновление до версии 7.5.1

Прямое обновление до версии 7.5.1 возможно с версий 7.3.3, 7.4.1, 7.4.2, 7.4.3 и 7.5.0.

Обновление с остальных версий возможно только после предварительного последовательного обновления до одной из перечисленных выше версий в соответствии с таблицей совместимости.
